## 🎯 內容準確性標準

### 1. 概念解釋準確性

#### ✅ 必須達到的標準：

- **定義準確**：使用業界公認的定義
- **來源可靠**：引用權威來源（論文、官方文檔、教科書）
- **上下文清晰**：說明適用範圍和限制條件
- **避免誤導**：明確指出常見誤解

#### 📝 驗證方法：

```markdown
### 示例：正確的概念解釋

**梯度下降 (Gradient Descent)**

**定義**：一種迭代優化算法，用於最小化目標函數。

**來源**：[Ruder, 2016. An overview of gradient descent optimization algorithms](https://arxiv.org/abs/1609.04747)

**核心思想**：
- 沿著函數梯度的反方向更新參數
- 步長由學習率控制

**適用場景**：
- ✅ 可微分的目標函數
- ✅ 參數空間連續
- ❌ 不適用於離散優化問題

**常見誤解**：
- ⚠️ 梯度下降不保證找到全局最優解（除非函數是凸函數）
- ⚠️ 學習率設置對收斂影響很大
```

### 2. 數學公式準確性

#### ✅ 必須達到的標準：

- **符號一致**：整個項目使用統一的數學符號
- **公式完整**：包含所有必要的條件和約束
- **推導正確**：數學推導步驟清晰無誤
- **實現驗證**：代碼實現與公式一致

#### 📊 符號規範：

| 概念 | 符號 | 示例 |
|------|------|------|
| 向量 | 小寫粗體 | **x**, **w** |
| 矩陣 | 大寫粗體 | **X**, **W** |
| 標量 | 斜體 | *n*, *α* |
| 集合 | 花體 | 𝒟, 𝒳 |

#### 🧮 公式驗證清單：

- [ ] 公式與參考文獻一致
- [ ] 所有符號都有定義
- [ ] 維度匹配正確
- [ ] 代碼實現與公式對應
- [ ] 包含數值示例驗證

### 3. 引用和來源

#### ✅ 必須達到的標準：

- **引用格式統一**：使用標準格式（APA、IEEE 等）
- **來源可追溯**：提供完整的引用信息
- **版本標註**：標明技術版本和時間
- **鏈接有效**：定期檢查外部鏈接

#### 📚 引用模板：

```markdown
## 參考資料

### 論文
```

## 💻 代碼質量標準

### 1. 代碼可運行性

#### ✅ 必須達到的標準：

- **環境明確**：清楚說明所需環境和依賴
- **完整可運行**：複製即可運行，無需額外修改
- **結果可復現**：設置隨機種子，確保結果一致
- **錯誤處理**：包含適當的異常處理

#### 🔍 可運行性檢查清單：

```python
# ✅ 好的代碼示例

"""
梯度下降優化器實現

環境要求：
- Python >= 3.9
- NumPy >= 1.24.0

運行方式：
    python gradient_descent.py

預期輸出：
    Epoch 100: Loss = 0.023
"""

import numpy as np

# 設置隨機種子以確保可復現性
np.random.seed(42)

def gradient_descent(X, y, learning_rate=0.01, epochs=100):
    """梯度下降優化器

    Args:
        X (np.ndarray): 特徵矩陣，形狀 (n_samples, n_features)
        y (np.ndarray): 目標變量，形狀 (n_samples,)
        learning_rate (float): 學習率，默認 0.01
        epochs (int): 訓練輪數，默認 100

    Returns:
        np.ndarray: 優化後的權重

    Raises:
        ValueError: 如果輸入維度不匹配

    Example:
        >>> X = np.array([[1, 2], [3, 4], [5, 6]])
        >>> y = np.array([1, 2, 3])
        >>> w = gradient_descent(X, y)
        >>> print(w.shape)
        (2,)
    """
    # 輸入驗證
    if X.shape[0] != y.shape[0]:
        raise ValueError(f"X 和 y 的樣本數不匹配: {X.shape[0]} vs {y.shape[0]}")

    # 初始化權重
    n_features = X.shape[1]
    w = np.zeros(n_features)

    # 梯度下降迭代
    for epoch in range(epochs):
        # 計算預測值
        y_pred = X @ w

        # 計算損失（MSE）
        loss = np.mean((y_pred - y) ** 2)

        # 計算梯度
        gradient = 2 * X.T @ (y_pred - y) / len(y)

        # 更新權重
        w -= learning_rate * gradient

        # 每 10 輪打印一次
        if (epoch + 1) % 10 == 0:
            print(f"Epoch {epoch + 1}: Loss = {loss:.6f}")

    return w


if __name__ == "__main__":
    # 生成示例數據
    X = np.random.randn(100, 2)
    true_w = np.array([3.0, -2.0])
    y = X @ true_w + np.random.randn(100) * 0.1

    # 運行梯度下降
    print("開始訓練...")
    w = gradient_descent(X, y, learning_rate=0.1, epochs=100)

    print(f"\n真實權重: {true_w}")
    print(f"學習權重: {w}")
    print(f"誤差: {np.abs(w - true_w)}")
```

```markdown
## 版本信息

|------|------|----------|------|

- 🔴 重大更新（破壞性變更）：需要更新所有相關代碼和文檔
```

```markdown
- ⏰ **計劃更新** (2022-03)：已列入更新計劃
```

## ✅ 審查流程

### 新內容審查清單

#### 第一階段：自審（創建者）

- [ ] **準確性**
  - [ ] 所有概念定義準確
  - [ ] 數學公式正確
  - [ ] 代碼可運行
  - [ ] 引用來源可靠

- [ ] **完整性**
  - [ ] 包含理論解釋
  - [ ] 包含代碼示例
  - [ ] 包含練習題
  - [ ] 包含參考資料

- [ ] **可讀性**
  - [ ] 結構清晰
  - [ ] 語言流暢
  - [ ] 圖表清楚
  - [ ] 代碼註釋充分

- [ ] **技術性**
  - [ ] 依賴版本明確
  - [ ] 環境配置清楚
  - [ ] 測試通過
  - [ ] 性能可接受

#### 第二階段：同行審查

- [ ] **技術審查**
  - [ ] 概念解釋無誤
  - [ ] 實現方式合理
  - [ ] 最佳實踐符合
  - [ ] 無安全隱患

- [ ] **教學審查**
  - [ ] 難度適當
  - [ ] 解釋清晰
  - [ ] 示例恰當
  - [ ] 練習有效
