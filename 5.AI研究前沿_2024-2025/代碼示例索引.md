## 🤖 Agent 系統示例

### 01_langgraph_workflow.py
**LangGraph - 可控的 Agent 工作流**

**核心特性：**
- ✓ 狀態圖工作流定義
- ✓ 條件路由與循環
- ✓ 多步驟推理
- ✓ 檢查點與持久化
- ✓ 與 LangSmith 集成

**實現內容：**
1. 簡單工作流示例
2. 研究型 Agent（規劃-研究-分析-寫作）
3. 條件路由示例
4. 狀態管理機制

**使用場景：**
- 複雜任務編排
- 多步驟推理系統
- 可控的 AI 工作流
- 生產級 Agent 應用

**快速開始：**
```python
from langgraph.graph import StateGraph

workflow = StateGraph(AgentState)
workflow.add_node("planner", plan_function)
workflow.add_node("executor", execute_function)
workflow.add_edge("planner", "executor")
app = workflow.compile()

result = app.invoke(initial_state)
```

**技術亮點：**
- 可視化工作流
- 靈活的狀態管理
- 內建錯誤處理
- 支持並行執行

**相關論文：**
- LangGraph: Building Stateful Multi-Actor Applications
- ReAct: Synergizing Reasoning and Acting

## 🔍 RAG 與檢索示例

### 01_graphrag_example.py
**GraphRAG - 知識圖譜增強檢索**

**核心特性：**
- ✓ 知識圖譜構建
- ✓ 圖結構化檢索
- ✓ 多跳推理支持
- ✓ 向量+圖混合檢索
- ✓ 子圖提取

**實現內容：**
1. 知識圖譜構建（實體+關係）
2. 向量相似度檢索
3. 圖擴展演算法
4. 多跳推理示例
5. 上下文構建

**使用場景：**
- 複雜問答系統
- 領域知識管理
- 多跳推理任務
- 知識密集型應用

**快速開始：**
```python
from graphrag import GraphRAG

# 建立 GraphRAG 實例
graph_rag = GraphRAG()

# 構建知識圖譜
graph_rag.build_knowledge_graph(documents)

# 檢索查詢
result = graph_rag.retrieve(
    query="GPT-4 使用什麼架構？",
    use_graph_expansion=True
)
```

**技術優勢：**
- 支持多跳推理（2-3跳）
- 結構化知識表達
- 更好的可解釋性
- 準確率提升 30-40%

**相關論文：**
- GraphRAG: Knowledge Graph-Enhanced Retrieval
- RAPTOR: Recursive Abstractive Processing

## ⚡ 訓練與優化示例

### 01_vllm_inference.py
**vLLM - 高性能 LLM 推理**

**核心特性：**
- ✓ PagedAttention 記憶體管理
- ✓ Continuous Batching
- ✓ 張量並行
- ✓ 高吞吐量推理
- ✓ OpenAI API 兼容

**實現內容：**
1. 基本推論引擎
2. 批量生成
3. 參數調優
4. 生產環境配置
5. 性能基準測試

**使用場景：**
- 高並發推論服務
- 批處理任務
- 實時 API 服務
- 大規模部署

**快速開始：**
```python
from vllm import LLM, SamplingParams

llm = LLM(
    model="meta-llama/Llama-2-7b-chat-hf",
    tensor_parallel_size=2
)

outputs = llm.generate(
    prompts=["Hello, my name is"],
    sampling_params=SamplingParams(temperature=0.7)
)
```

**性能提升：**
- 吞吐量: 15-24x vs Hugging Face
- 記憶體效率: 2-4x 提升
- 延遲: 接近理論最優

**相關論文：**
- vLLM: Efficient Memory Management for LLM Serving
- FlashAttention: Fast and Memory-Efficient Attention

### 02_qlora_finetuning.py
**QLoRA - 高效模型微調**

**核心特性：**
- ✓ 4-bit 量化（NF4）
- ✓ LoRA 低秩適配
- ✓ 雙重量化
- ✓ 8-bit Adam 優化器
- ✓ 單卡微調 70B+ 模型

**實現內容：**
1. 量化配置
2. LoRA 配置
3. 訓練流程
4. 資料處理
5. 推理與部署

**使用場景：**
- 資源受限的模型微調
- 領域適配
- 指令微調
- 多任務學習

**快速開始：**
```python
from qlora_trainer import QLoRATrainer

trainer = QLoRATrainer(
    model_name="meta-llama/Llama-2-7b",
    lora_r=16,
    lora_alpha=32
)

model, tokenizer = trainer.load_model()
trainer.train(train_dataset)
```

**記憶體節省：**
| 模型大小 | 全量微調 | QLoRA | 節省 |
|---------|---------|-------|------|
| 7B | ~28GB | ~5GB | 5.6x |
| 13B | ~52GB | ~8GB | 6.5x |
| 70B | ~280GB | ~48GB | 5.8x |

**相關論文：**
- QLoRA: Efficient Finetuning of Quantized LLMs
- LoRA: Low-Rank Adaptation of Large Language Models

## 🔧 故障排除

### 常見問題

**1. CUDA Out of Memory**
```python
# 解決方案：
# 1. 降低批次大小
# 2. 啟用 gradient checkpointing
# 3. 使用 CPU offload
model.enable_model_cpu_offload()
```

**2. vLLM 初始化失敗**
```bash
# 檢查 CUDA 版本
nvidia-smi

# 重新安裝 vLLM
pip uninstall vllm
pip install vllm --no-cache-dir
```

**3. QLoRA 訓練速度慢**
```python
# 優化方案：
# 1. 使用 Flash Attention
attn_implementation="flash_attention_2"

# 2. 啟用 bf16
torch_dtype=torch.bfloat16

# 3. 使用較小的 LoRA 秩
lora_r=8  # 而不是 64
```

**4. LangGraph 狀態錯誤**
```python
# 確保狀態類型定義正確
from typing import TypedDict

class State(TypedDict):
    messages: list  # 明確定義類型
    count: int
```
