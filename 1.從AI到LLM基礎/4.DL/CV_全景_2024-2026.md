# 電腦視覺全景分析 2024-2026

> 對應 [全景圖](../../2024-2026_AI完整領域全景圖.md) #5
> 從基礎 detection 到 VLA,8 條軸線描繪 CV 在 2024-2026 的轉折。

---

## 1. 物件偵測與分割:從封閉類別到開放概念

產業仍以 Ultralytics 的 YOLO 系列為事實標準:
- **YOLOv8** (2023) 鞏固 anchor-free + 多任務範式
- **YOLOv9**:PGI + GELAN
- **YOLOv10** (清華):首次端到端去 NMS
- **YOLOv11** (2024):C3k2/C2PSA
- **YOLOv12** (2025/02):Area Attention + R-ELAN + FlashAttention
- **YOLO26** (2026/01):全新世代,原生 NMS-free、移除 DFL,nano 模型 CPU 推論最多降 43%
- **YOLOv13**:transition 到 attention-centric

**SAM 3 (Meta, 2025/11)**:從 SAM 2 的 promptable mask 升級為 **Promptable Concept Segmentation (PCS)**——給文字或範例就能找出整張影像/影片中該概念的**所有實例**。**SAM 3.1 (2026/03)** 加上 Object Multiplex,共享記憶體實現多物件聯合追蹤。

**Grounding DINO** (ECCV 2024) 仍是開放詞彙偵測的主力,常與 SAM 組成 "Grounded-SAM" pipeline 做 text-to-mask。

**選型**:即時封閉類別 → YOLO26 / YOLO11;高精度且能容忍延遲 → RT-DETR/RF-DETR;開放詞彙偵測 → Grounding DINO + SAM 3;影片追蹤分割 → SAM 2/3。

## 2. 視覺骨幹模型:自監督接管預訓練

CNN backbone (ResNet, ConvNeXt) 已退居二線。**自監督預訓練**:MAE、**DINOv2** (1B params, 142M images) 已成 dense prediction 的事實標準特徵抽取器。

**DINOv3 (Meta, 2025/08)**:7B 參數 ViT teacher,訓練 17 億張影像,引入 **Gram anchoring** 解決 dense feature map 退化。首次證明**自監督在多項任務上勝過弱監督**(SigLIP 2、Perception Encoder),商業授權釋出。

**V-JEPA 2 (Meta, 2025/06)**:LeCun 路線的 video world model,訓練於~百萬小時網路影片。V-JEPA 2-AC 從 62 小時無標註觀察影片學得物理世界模型,在全新環境 16 秒內規劃並完成「移杯」任務 (80% 成功率)。代表 SSL 從「特徵抽取」走向「世界模型 + 規劃」。

**心法**:任何 dense prediction / few-shot 任務,**DINOv3 frozen backbone + linear/lightweight head** 已是最強 baseline。

## 3. 3D 視覺與新視角合成:3DGS 逐漸取代 NeRF

NeRF (2020) 訓練慢、渲染慢。**3D Gaussian Splatting (SIGGRAPH 2023)** 用顯式 Gaussians + tile-based rasterization,訓練分鐘級、渲染 60+ FPS,**2026 在多數實用場景已成主流**。

**2025-2026**:
- **gsplat (Nerfstudio)**:省 4× 記憶體
- **4D Gaussian Splatting**:Anchored 4DGS (SIGGRAPH Asia 2025)、**MEGA**(13M Gaussians 壓到 0.91M)、**4DGS-1K**(1000+ FPS、41× 儲存壓縮)
- **3DGS-SLAM**:LEGO-SLAM 等系統把 Gaussian 表示直接做為地圖,15 FPS open-vocabulary mapping
- **Mesh extraction**(SuGaR, 2DGS):3D 資產 pipeline 主流

**選型**:靜態重建 → gsplat + Nerfstudio;動態場景 → MEGA / 4DGS-1K;SLAM → 3DGS-SLAM;需傳統 DCC 相容 → SuGaR/2DGS 轉 mesh。

## 4. 影像生成:Flow Matching 與 DiT 取代 U-Net Diffusion

- **SDXL** (2023):社群生態最大宗
- **Stable Diffusion 3 / 3.5** (2024):**MMDiT + Rectified Flow**
- **FLUX.1** (Black Forest Labs, 2024):12B Flow Matching + hybrid transformer,在 prompt 遵循、文字渲染、人體解剖三項全面超越 SDXL,2026 開源最強
- 閉源:DALL-E 3、Imagen 3、Midjourney v7

**2025-2026 突破**:
- **Flow Matching / Rectified Flow** 在新訓練 frontier 影像/影片模型已逐漸取代 DDPM denoising
- **Consistency Models / LCM / DMD** 把推論壓到 1-4 步
- **DiT** 成為新架構共識
- 文字渲染:FLUX ~95%、SD 3.5 ~60%、SDXL 幾乎無法做

## 5. 影片生成:DiT 統一範式

- **Sora 2** (2025/12, Pro 2026/01):物理一致性領先
- **Veo 3 / 3.1** (Google):廣播級畫質,原生 48kHz 音訊 + 4K
- **Kling 3.0** (Kuaishou, 2026/02):原生 4K 60fps、多鏡頭 storyboard
- **Runway Gen-3 / Gen-4、Pika、Seedance 2.0** (ByteDance)
- **開源**:Hunyuan Video (騰訊)、Wan 2.x (阿里) 已可本地跑出可用影片

**技術範式**:所有主流模型都收斂到 **3D-VAE 壓縮 + spatio-temporal DiT + Flow Matching**;音訊接 audio-DiT 同步生成。

## 6. VLM:Native Multimodal 已成主流

從 LLaVA (2023, 拼接 CLIP + LLM) 演進到 **native multimodal**——從預訓練第一天就混合圖文 token,代表 **GPT-4o、Gemini 2.x、Claude 3.5/3.7 Sonnet**。

**2025-2026**:
- **Qwen2.5-VL → Qwen3-VL** (235B-A22B MoE / 30B-A3B):Instruct + Thinking 雙版本 + FP8
- **InternVL3 → InternVL3.5** (241B-A28B MoE):開源 MLLM SOTA
- **LLaVA-OneVision 1.5**:以 Qwen3 為 backbone,全開源
- 趨勢:**任意解析度 patch、video token 壓縮、thinking-mode VLM、agentic VLM (GUI 操作)**

## 7. 具身視覺 / Robotics:VLA 是新典範

- **RT-2** (Google DeepMind, 2023):VLA 概念開創
- **OpenVLA** (Stanford, 2024/06, 7B):首個全開源 VLA,訓練於 Open X-Embodiment
- **π0 / π0-FAST** (Physical Intelligence):VLM backbone + **Flow Matching** 連續動作生成,動作平滑度與多模態分佈處理超越離散 token
- **SmolVLA**:輕量 VLA 探索消費級硬體部署

**選型**:研究入門 → OpenVLA + LeRobot;產品化 dexterous manipulation → π0 / OpenPi fine-tune;規劃導向研究 → V-JEPA 2。

## 8. CV 工程實踐:邊緣部署成熟化

訓練端 **PyTorch + timm + TorchVision**;部署端 **ONNX 為中介、TensorRT/OpenVINO/CoreML/TFLite 為終點**。

**2025-2026**:
- **YOLO26 edge-first**:原生 NMS-free + 無 DFL,匯出 ONNX/TensorRT/CoreML/TFLite **不需要客製 plugin**
- **ONNX Runtime** 統一 execution provider:CUDA / TensorRT / DirectML / OpenVINO / CoreML / QNN
- **TensorRT 10 + FP8 / INT4**:Hopper/Blackwell GPU 上量化擴散到 vision
- **Apple Neural Engine + CoreML 8**:Vision Transformer 與 SD-class diffusion 已可在 iPhone 即時跑

## 2026 入門 CV 工程師最短路徑

1. **打地基 (2 週)**:PyTorch + timm,在 ImageNet/CIFAR 跑通 ViT 與 ResNet
2. **掌握完整 pipeline (4 週)**:用 Ultralytics YOLO26 / YOLO11,從 Roboflow 標一個自己的資料集,訓練 → 評估 → 匯出 ONNX → TensorRT 部署到 Jetson 或 CoreML 部署到 iPhone。**這條 pipeline 是 90% CV 工作的縮影**
3. **加上開放詞彙 (2 週)**:玩 Grounding DINO + SAM 3
4. **吃下一個 foundation backbone (2 週)**:用 DINOv3 frozen feature 做 few-shot 分類 / retrieval / depth probe
5. **選一個垂直深入 (8 週,擇一)**:
   - **生成方向** → diffusers + FLUX.1 / SD3.5 + LoRA + ControlNet,延伸到 video
   - **3D 方向** → Nerfstudio + gsplat,從手機影片重建 3DGS
   - **多模態方向** → Qwen2.5-VL / InternVL3 微調
   - **Robotics 方向** → LeRobot + OpenVLA / π0

**一條鐵律**:不要再花時間從零實作 ResNet/UNet — 2026 年的 CV 工程價值集中在 **(a) 資料工程 + (b) foundation model 微調與蒸餾 + (c) 跨硬體部署**。
