Exploring Video Quality Assessment on User Generated Contents from Aesthetic and Technical Perspectives

這篇論文的大綱如下：

用戶生成內容 (UGC) 影片的快速增長呼籲開發有效的影片品質評估 (VQA) 演算法。然而，UGC-VQA 的目標常常模稜兩可，包含了技術層面（衡量失真）和美學層面（與內容偏好和推薦相關）。作者進行了一項大規模的主觀研究，收集人們對整體影片品質的意見，以及對美學和技術方面的看法。由此產生的分離影片品質資料庫 (DIVIDE-3k) 證實，人們對 UGC 影片的質量意見受到美學和技術因素的影響。基於此，作者提出了 DOVER，一種分離客觀影片品質評估器，它從兩個角度學習影片品質，在 UGC-VQA 中實現了最先進的性能，效率很高。此外，他們還介紹了 DOVER++，這是第一種從單一美學或技術角度提供可靠品質評估的方法。 

**1. 簡介**

* UGC 視訊品質評估 (VQA) 的重要性與挑戰
* 技術和美學觀點對 VQA 的影響
* 本文貢獻：DIVIDE-3k 資料庫、DOVER 和 DOVER++ 模型

近年來，使用者生成內容 (UGC) 的影片數量激增，如何評估這些影片的質量成為了一個重要課題。傳統的影片品質評估 (VQA) 主要關注技術層面，例如分辨率、幀率等。然而，對於 UGC 影片，美學因素，如構圖、色彩等，同樣對觀眾的觀感產生重大影響。

現有的研究表明，技術和美學角度都會影響人們對 UGC 影片品質的感知。然而，目前缺乏同時考慮這兩個角度的客觀 VQA 方法。為填補這一空白，研究人員進行了大規模的主觀研究，收集了大量 UGC 影片，並從美學、技術和整體三個維度進行了品質評估。

基於這些主觀資料，研究人員構建了一個名為 DIVIDE-3k 的全新 UGC-VQA 資料庫，這是首個包含美學和技術角度評價的資料庫。此外，他們還提出了一種名為 DOVER 的主觀啟發式影片品質評估方法。DOVER 包含兩個分支，分別關注美學和技術特徵，並將兩者融合以預測影片的整體質量。


**2. 相關工作**

* UGC-VQA 資料庫和主觀研究
* UGC-VQA 客觀方法

這段文章主要討論了 UGC-VQA（User Generated Content - Video Quality Assessment）領域的研究現狀，特別關注了資料庫、主觀研究和客觀方法的發展。

傳統 VQA 資料庫主要收集專業製作的影片，而 UGC-VQA 資料庫則直接從現實世界中收集，內容和製作水平差異更大，主觀評估也更具挑戰性。

早期的 UGC-VQA 方法多採用手工特徵，但忽略了語義對質量感知的影響。近年來，深度學習方法興起，開始考慮語義因素，並取得了一定進展。然而，這些方法仍受限於主觀標註的模糊性，難以解釋其質量預測的依據，限制了在實際場景中的應用。

總體來說，UGC-VQA 仍是一個充滿挑戰的研究領域，需要更多高品質的資料庫和可解釋的客觀方法來推動其發展。

**3. DIVIDE-3k 資料庫**

* 視訊收集來源
* 主觀研究設計與執行
* 觀察與發現

DIVIDE-3k 是一個包含 3,590 個 UGC 影片的資料庫，收集自 YFCC-100M 和 Kinetics-400。為了確保樣本代表性，研究人員從 400,000 個影片中選取了 3,270 個，並從 LSVQ 中選取了 320 個。所有影片都經過處理以匹配原始資料庫的質量分佈。 

研究人員為了確保評估結果的準確性，進行了一系列嚴謹的實驗室主觀評估。他們首先培訓評分員，確保他們充分理解美學和技術這兩個評估維度。然後，他們提供了明確的評分標準和示例，幫助評分員做出更客觀的判斷。

在評估過程中，評分員需要對每個影片的美學、技術和整體質量進行評分。此外，他們還需要評估技術因素對整體質量的影響程度。為了確保評分質量，研究人員在評估過程中插入了一些預先評分過的「用於品質控制的基準影片」。評分員對這些用於品質控制的基準影片的評分將與預設分數進行比較，以確保評分的一致性和準確性。 這個實驗室主觀評估過程旨在確保資料的可靠性和評估結果的客觀性，為後續研究提供堅實的基礎。 

在第 3.3 節 **Observations（觀察結果）** 中，作者對美學與技術兩個評估視角對影片總體質量的影響進行了分析。他們首先定量評估了這兩個視角與總體質量的相關性，使用了 Spearman 和 Kendall 相關係數來衡量。結果顯示，將美學與技術評分加權合併後的總體品質評估效果，比僅依賴單一視角來進行預測更加準確。

具體來說，技術視角與美學視角的結合，能更好地反映用戶對於影片品質的整體感知。圖 4 的結果也支持這一觀察，即在每個維度中的最佳與最差影片，明顯受到這兩個因素的共同影響。

此外，為了驗證這一發現是否適用於現有的用戶生成內容影片品質評估（UGC-VQA）研究，研究者選取了 320 段來自 LSVQ 資料集的影片，進行了跨資料庫的比對。結果顯示，總體質量得分與現有的 UGC-VQA 資料中的評分高度相關，進一步表明結合美學與技術評分來預測總體質量是可行且準確的。

最後，這一節提出了從多角度考慮人類品質評估（美學與技術的融合）會更準確地反映用戶對影片品質的實際感知。

**4. 方法：DOVER 和 DOVER++**

* 觀點分解策略
* 美學分支
* 技術分支
* 學習目標
* 主觀啟發的融合策略

第四章討論了「DOVER 和 DOVER++」的評估方法，這些方法旨在同時考慮美學與技術兩個角度來進行用戶生成內容（UGC）的影片品質評估。

   在「DIVIDE-3k」資料集中，作者觀察到美學和技術這兩個評估角度往往與不同的視覺特徵相關聯。美學評估通常與影片的語義、構圖等高層次視覺感知有關，而技術評估則與影片中的低層次失真（例如模糊、噪點、失焦等）相關。

   為了更準確地預測影片品質，作者提出了「視覺分解策略」，將美學視角和技術視角分別處理，並建立兩個獨立的分支來進行品質評估：
   - **美學視角（SA）**：關注於影片的語義和構圖。
   - **技術視角（ST）**：關注於影片中的技術失真。

   最終，這兩個視角的預測結果會融合為最終的品質評估結果。

之後作者詳細介紹了如何讓模型專注於影像的美學特徵，從而提升其對影像品質的評估能力。這一部分的目標是幫助模型在美學角度上進行有效的影片品質評估，而不被技術失真干擾。

首先，**美學視角 (SA)** 被定義為專注於影片的語義和構圖，這些是決定影片美感的關鍵因素。為了實現這一目標，作者引入了兩個重要技術：**空間下採樣**（spatial downsampling）和 **時間稀疏幀抽樣**（temporal sparse frame sampling）。這些技術可以減少對影片技術細節（如失真、雜訊等）的敏感度，從而幫助模型更好地捕捉美學資訊。

具體來說，**下採樣技術** 是降低影片解析度的一種方法，這樣模型可以專注於高層次的視覺特徵，例如語義和構圖，而不是技術失真。作者將影片的分辨率減少了多達 11.3%，這使得模型在更小的影像範圍內，仍然能夠保持良好的美學判斷。

此外，作者引入了**跨尺度正則化（Cross-scale Regularization）**，這是一種減少技術干擾的技術手段。通過這種正則化，模型可以在多個尺度上進行學習，並保持一致的美學評分，不會因技術失真而受到過多影響。這使得模型可以更專注於美學層面的影片分析，忽略像是模糊、抖動、雜訊等技術問題。

總之，美學分支的設計目的是通過降低技術失真的影響，專注於影片的高層次特徵（如語義、構圖等），從而提升對影片美感的評估精度。這一方法為美學品質評估提供了一個有效的框架，同時減少了技術失真對評估結果的干擾。

在技術分支中，目標是保留影像中的技術失真，同時弱化其美學屬性。技術視角（ST）的設計旨在保持對技術失真的專注，例如模糊、雜訊等，但去除語義和構圖等高層次的美學資訊。具體實現上，技術分支使用了隨機裁剪的圖像碎片，這些碎片拼接在一起以保持技術失真，但破壞了美學的連貫性。此外，技術分支還應用了**連續幀時間稀疏抽樣**來保持技術失真資訊。

在學習目標這部分，作者討論了如何弱監督兩個分支。首先，基於 3.3 節中的觀察，作者提出可以將總體品質評估（MOS）近似為技術評分和美學評分的加權總和，並提出了「有限視角監督」（Limited View Biased Supervisions，LVBS），以最小化兩個分支與總體質量之間的預測誤差。此外，作者提出了「直接監督」（Direct Supervisions，LDS），以提高技術分支與美學分支各自的預測精度。

在觀啟發的融合策略這裡，作者根據實驗得出一個基於兩個視角的加權總和策略，MOS 可以近似為 0.428 的美學分數加上 0.572 的技術分數。該策略有效地結合了兩個分支的評估結果，並在實驗中展示了良好的性能表現。

這些部分共同構成了 DOVER 和 DOVER++ 模型的核心方法，結合技術與美學的雙視角，並通過不同的正則化與監督技術來優化最終的影片品質評估。

**5. 實驗評估**

* 實現細節和資料集
* 兩種觀點的評估
* 整體品質預測評估
* 消融實驗
* 個人化品質評估展望

第五章主要進行了對 DOVER 和 DOVER++ 模型的實驗評估，檢驗它們在不同視角下的表現，並探索這些方法在 UGC-VQA（用戶生成內容影片品質評估）問題中的應用效果。

5.1這一節詳細描述了在進行實驗評估時的具體設置。在美學分支中，作者使用了 224x224 尺寸的影像進行推理，並在訓練期間將其下採樣到 128x128。這樣的設置是為了更好地捕捉美學資訊，同時減少對技術失真的敏感度。技術分支則保留了更多的技術細節，以專注於影片中的失真和質量損失。這些設置幫助確保兩個分支都能專注於各自的評估維度。

這部分的設置目的是使模型能夠同時對美學和技術細節進行準確的質量預測，並在實際的 UGC 場景中進行有效應用。

在第五章的 5.2 節，作者探討了對 DOVER 和 DOVER++ 模型進行的兩個視角的評估。具體來說，該部分分為以下幾個重點內容：

### 5.2.1 在 DIVIDE-3k 上的評估
- **定量研究**：表 3 展示了在 DIVIDE-3k 資料集上 DOVER 和 DOVER++ 的性能，並與現有基線方法進行了比較。實驗結果表明，DOVER 在使用兩個視角（美學與技術）進行評估時，預測結果與人類主觀意見高度相關。
- **定性研究**：圖 6 可視化展示了 DOVER/DOVER++ 在美學和技術視角上分歧較大的影片。具體來說，圖中顯示了一些影片在美學上表現優異，但在技術上則因模糊或雜訊而有所下降，這證實了兩個視角的評估結果確實可以有效區分不同的質量標準。

### 5.2.2 在現有的 UGC-VQA 資料集上的評估
- **分歧圖研究**：圖 7 展示了 LSVQ 資料集中美學與技術分數差異最大的影片，並進一步探討了這些影片中兩個視角分數差異的原因。結果表明，美學和技術分支能夠有效地區分失真的來源，並在不同的影片品質上提供準確的預測。
- **用戶調查**：作者進行了一個配對用戶調查，讓受試者根據分歧較大的影片來選擇其偏好的視角。結果顯示，用戶的選擇與相應的模型預測結果大致一致，進一步證實了 DOVER 模型的實際應用價值。


在 5.3 節中，作者討論了 DOVER 和 DOVER++ 模型在「整體質量預測」方面的表現，分別在現有的 UGC-VQA 資料集和 DIVIDE-3k 資料集上進行了實驗。

### 5.3.1 在現有 UGC-VQA 資料集上的結果
- **LSVQ 資料集上的表現**：表 4 展示了 DOVER 模型在 LSVQ 資料集上的表現。DOVER 模型在這個大規模資料集上的評估結果顯示，它的性能優於現有的多種基線模型，尤其是在 PLCC 和 SRCC 評估指標上有明顯提升。該結果證明了 DOVER 模型能夠在大資料集上的良好泛化能力，並能夠有效處理 UGC 場景中的影片品質評估。
- **較小的 UGC-VQA 資料集上的結果**：DOVER 模型還在更小的資料集上進行了測試，包括 KoNViD-1k 和 YouTube-UGC。結果顯示，DOVER 在這些資料集上的表現也超越了其他基線模型，表明該方法在不同資料集和影片品質評估任務中具有良好的通用性。

### 5.3.2 在 DIVIDE-3k 上的結果
- **在 DIVIDE-3k 上的訓練與測試**：表 6 展示了 DOVER 和 DOVER++ 模型在 DIVIDE-3k 資料集上的表現。結果顯示，這兩個模型在該資料集上的表現同樣優於其他基線方法，特別是在結合美學和技術評分後，DOVER++ 模型能夠顯著提高整體質量預測的精度。
- **零樣本和跨資料集評估**：作者還測試了 DOVER 模型在零樣本（未經訓練的資料）和跨資料集評估中的表現，結果表明，DOVER 模型在不同資料集上的表現一致，進一步證明了它在泛化和應用中的穩定性。

### 5.4 **消融研究（Ablation Studies）**
在 5.4 節中，作者進行了消融研究，旨在評估「視角分解策略」的有效性，以及不同目標函式對模型的影響。

- **視角分解策略的影響**：表 8 中展示了消融研究結果，作者比較了不使用視角分解的模型與使用視角分解的模型。結果表明，使用視角分解能夠顯著提高美學和技術分支的預測性能。這證實了將美學和技術特徵分開進行處理的有效性，比直接將所有資訊作為輸入來進行預測的方式更加準確。
- **主觀啟發融合策略的影響**：表 9 中展示了不同融合策略的消融結果。結果顯示，使用加權融合（即根據主觀啟發的權重來結合美學和技術預測）的模型效果最佳，這表明在美學和技術的結合過程中，合理分配權重可以提高總體質量預測的精度。

這部分研究證實了「視角分解策略」和「主觀啟發融合策略」在提升模型性能方面的關鍵作用。

### 5.5 **展望：個性化品質評估（Outlook: Personalized Quality Evaluation）**
5.5 節探討了個性化品質評估的潛力，特別是根據個人偏好的差異來進行質量預測。

- **不同個體的視角偏好**：作者觀察到，不同的受試者在評估影片品質時，對美學和技術的重視程度各不相同。圖 9 展示了具有不同美學和技術質量的影片，並且說明了有些人會更看重技術質量（如畫面清晰度），而另一些人則更注重美學因素（如構圖和語義）。
- **個性化品質評估的未來**：基於這一觀察，DOVER++ 可以根據個體的偏好進行加權融合，從而提供個性化的品質評估。這為未來的研究提供了方向，即開發能夠根據用戶個性化需求進行質量預測的系統。

總體來說，5.5 節指出了 DOVER 和 DOVER++ 在未來應用中的潛力，尤其是在為不同用戶提供個性化的影片品質評估方面，這可能是一個重要的發展方向。

**6. 結論**

* 總結研究成果和貢獻
* 強調 DOVER 和 DOVER++ 的優勢和潛在應用

本研究提出了一個創新的 UGC 影片品質評估框架，主要貢獻包括：

**主要成果：**

1. **DIVIDE-3k 資料庫**：首個包含美學和技術雙重評估維度的大規模 UGC-VQA 資料庫，包含 3,590 個影片樣本，為後續研究提供了寶貴的資料資源。

2. **DOVER (Disentangled Objective Video quality EvaluatoR)**：
   - 採用視角分解策略，分別處理美學和技術特徵
   - 在多個 UGC-VQA 基準測試中達到最先進的性能
   - 計算效率高，適合實際應用場景
   - 美學分支專注於語義和構圖，技術分支專注於失真檢測

3. **DOVER++**：首個能夠從單一美學或技術角度提供可靠品質評估的方法，支援個性化品質評估。

**技術優勢：**

- **解釋性強**：明確區分美學和技術因素，使品質評估結果更具可解釋性
- **泛化能力強**：在跨資料集評估中表現優異，證明了方法的穩健性
- **實用性高**：可根據不同應用場景和用戶偏好調整美學與技術的權重比例

**潛在應用：**

1. **內容推薦系統**：根據用戶對美學或技術質量的偏好進行個性化影片推薦
2. **影片平台品質控制**：自動篩選和評估用戶上傳的影片內容
3. **影片壓縮與編碼**：評估壓縮演算法對美學和技術質量的影響
4. **影片編輯輔助**：為內容創作者提供質量反饋和改進建議
5. **廣告投放優化**：根據影片品質評估優化廣告投放策略

**研究意義：**

本研究不僅推動了 UGC-VQA 領域的技術進步，更重要的是為理解人類對影片品質的感知提供了新的視角。通過將品質評估分解為美學和技術兩個維度，DOVER 為未來的個性化影片服務和智能內容管理系統奠定了基礎。

## 7. 技術實現細節

### 7.1 模型架構

**DOVER 架構組成：**

1. **美學分支 (Aesthetic Branch)**
   - 輸入處理：空間下採樣至 128×128（訓練時）/ 224×224（推理時）
   - 時間採樣：稀疏幀抽樣（每 4 幀抽取 1 幀）
   - 骨幹網絡：ConvNeXt-Tiny（預訓練於 ImageNet-1K）
   - 特殊技術：跨尺度正則化（Cross-scale Regularization）

2. **技術分支 (Technical Branch)**
   - 輸入處理：保持原始分辨率，隨機裁剪拼接
   - 時間採樣：連續幀抽樣（保持時序失真資訊）
   - 骨幹網絡：ConvNeXt-Tiny
   - 專注於：低層次失真（模糊、噪點、壓縮失真等）

3. **融合策略**
   - 加權融合：MOS ≈ 0.428 × SA_score + 0.572 × ST_score
   - 可根據應用場景調整權重

### 7.2 訓練策略

**損失函式：**

```
L = L_VBS + L_DS

其中：
- L_VBS: 有限視角偏差監督（Limited View Biased Supervisions）
- L_DS: 直接監督（Direct Supervisions）
```

**關鍵技術：**

1. **跨尺度正則化**：確保美學分支在不同分辨率下保持一致的評分
2. **隨機裁剪拼接**：破壞美學連貫性，強制技術分支關注失真
3. **弱監督學習**：僅使用整體質量標籤訓練兩個分支

### 7.3 性能指標

在主要 UGC-VQA 資料集上的表現：

| 資料集 | SRCC | PLCC | 說明 |
|--------|------|------|------|
| LSVQ | 0.876 | 0.894 | 大規模測試集 |
| KoNViD-1k | 0.895 | 0.907 | 中等規模 |
| YouTube-UGC | 0.812 | 0.826 | 跨平台泛化 |
| DIVIDE-3k | 0.912 | 0.921 | 新提出的資料集 |

**計算效率：**
- 推理時間：約 0.5 秒/影片（使用單個 GPU）
- 模型參數：約 28M（美學分支） + 28M（技術分支）

### 8.2 模型使用

**基本使用範例：**

```python
import torch
from dover import DOVER

# 載入模型
model = DOVER(pretrained=True)
model.eval()

# 評估影片
video_path = "sample_video.mp4"
with torch.no_grad():
    aesthetic_score, technical_score, overall_score = model(video_path)

print(f"美學評分: {aesthetic_score:.3f}")
print(f"技術評分: {technical_score:.3f}")
print(f"整體評分: {overall_score:.3f}")
```

**個性化評估：**

```python
# 調整權重以適應不同應用場景
def custom_evaluation(aesthetic_score, technical_score, aesthetic_weight=0.5):
    technical_weight = 1 - aesthetic_weight
    return aesthetic_weight * aesthetic_score + technical_weight * technical_score

# 強調美學（適合藝術影片）
artistic_score = custom_evaluation(aesthetic_score, technical_score, aesthetic_weight=0.7)

# 強調技術（適合專業影片）
professional_score = custom_evaluation(aesthetic_score, technical_score, aesthetic_weight=0.3)
```

### 8.3 常見問題與解決方案

**Q1: 模型評估速度慢怎麼辦？**
- A: 可以調整幀採樣率，減少處理的幀數
- 使用多 GPU 並行處理批量影片

**Q2: 如何處理不同分辨率的影片？**
- A: DOVER 會自動調整輸入大小，但建議預處理為統一分辨率以獲得最佳性能

**Q3: 評分結果如何解讀？**
- A: 評分範圍通常在 0-5 或 0-100（取決於實現），分數越高表示質量越好
- 美學分數主要反映內容吸引力，技術分數主要反映視覺清晰度
