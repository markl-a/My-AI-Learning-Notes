# 📚 卷積神經網路 (CNN) 完整學習路徑

## 🎯 學習目標

本模組將帶你從零開始系統學習卷積神經網路，從基礎理論到實戰應用，最終能夠：
- 理解 CNN 的工作原理和設計思想
- 掌握卷積、池化等核心操作
- 能夠從零實現經典 CNN 架構
- 運用遷移學習解決實際問題
- 掌握 CNN 的調試和優化技巧

---

## 📖 學習路徑

### 🌟 階段一：基礎理論（2-3 天）

#### 1. [為什麼使用卷積](1_why-conv.ipynb) ⭐⭐⭐
**學習重點：**
- 全連接層的局限性
- 平移不變性和局部性原則
- 卷積操作的數學基礎
- 感受野的概念

**實踐練習：**
- ✅ 證明 Δ=0 時卷積等價於全連接
- ✅ 分析平移不變性的優缺點
- ✅ 處理圖像邊界的策略
- ✅ 設計音頻卷積層
- ✅ 文本數據的卷積應用

**預計時間：** 4-6 小時

---

#### 2. [卷積層詳解](2_conv-layer.ipynb) ⭐⭐⭐⭐

- 從零實現卷積層
- 邊緣檢測實戰
- 學習卷積核參數
- 特徵映射和感受野

**實踐練習：**
- ✅ 對角線邊緣檢測
- ✅ 自動求導機制分析
- ✅ 卷積轉矩陣乘法
- ✅ 手工設計特殊卷積核

#### 5. [池化層](5_pooling.ipynb) ⭐⭐⭐

## 🛠️ 開發環境

### 推薦配置

```python
# Python 版本
Python >= 3.8

# 核心庫
torch >= 2.0.0
torchvision >= 0.15.0
numpy >= 1.21.0
matplotlib >= 3.5.0
tqdm >= 4.65.0
Pillow >= 9.0.0

# 可視化和分析
tensorboard >= 2.12.0
seaborn >= 0.12.0
opencv-python >= 4.7.0

# Jupyter 環境
jupyter >= 1.0.0
ipywidgets >= 8.0.0
```

### 硬件建議

**最低配置：**
- CPU: 4 核心
- RAM: 8GB
- 存儲: 10GB

**推薦配置：**
- CPU: 8 核心以上
- RAM: 16GB 以上
- GPU: NVIDIA GPU (6GB+ VRAM) 或 Apple Silicon (M1/M2/M3)
- 存儲: 20GB 以上
