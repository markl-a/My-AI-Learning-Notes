## 適用對象

### 主要對象

1. **求職者**(0–2 年經驗):工程師 / DS / 資料分析師想進入 AI 領域。重點看 01(選方向)+ 02(履歷)+ 03(面試)。
2. **轉職者**(3–8 年其他工程師):從 web / data engineer / mobile 轉 AI,擔心自己缺 ML 背景。重點看 01 的「軟體工程師 → AI Engineer 最短路」與 02 的「殺手項目」三類。
3. **想懂 AI 的 PM / 跨職能人員**:不一定要寫程式,但需要在 AI 團隊裡決策、評估候選人。重點看 01(認識職位地圖)+ 03 結尾的「Top 5 LLM 工程師問題」(知道該問什麼)。

### 次要對象

- **Senior 工程師回鍋面試**:多年沒面試、不熟 STAR 套路。03 + 02 末段的「最後 24 小時」清單。
- **大學 / 研究所學生**:還沒畢業但想預先規劃。01 + 04 的學習節奏。

## 三條建議讀法

- **30 分鐘速覽版**:讀完本 README → 02 的殺手項目段 → 03 的 Top 5 LLM 工程師問題。可立即決定下一步行動。
- **完整準備版**(2–3 週):依序讀 01 → 02 → 03 → 04,每章對應 3–5 天執行(改履歷、刷 STAR、寫部落格文章)。
- **長線經營版**:把 04 變成每月習慣,每季回看 01 確認職涯方向是否需要調整。

## phantom-mesh 在本目錄的角色

[phantom-mesh](https://github.com/markl-a/phantom-mesh) 是本知識庫對應的開源 multi-agent runtime。
本目錄第 03 章的 STAR 範例中,**至少 5 個答案取材自 phantom-mesh 真實開發場景**
(provider fallback、SSE 串流解析、跨平台 build、multi-agent 協調、cost tracking),
讓「我做過什麼」可以指向具體 commit / PR / issue,而不是空泛敘述。
