## 為什麼圖:四個典型場景

1. **社群網路與推薦**: 用戶-用戶/用戶-商品自然是圖,GNN 直接吃結構 (e.g. Pinterest PinSage、Twitter/X 推薦圖譜)。
2. **分子性質預測**: 原子 = 節點、鍵 = 邊,化學家直覺。AI4Drug 主力工具。
3. **知識圖譜推理**: Freebase/Wikidata 的 (head, relation, tail) 三元組,LLM 時代 GraphRAG 重新崛起。
4. **大規模推薦系統**: Alibaba、Meta、TikTok 都把 user-item interaction 當圖,GNN 做 candidate retrieval / ranking 已產業標配。

如果你的問題天然帶「節點 + 關係」結構,GNN 通常贏過硬扁平化的 MLP/Transformer。

## 先決條件

- **PyTorch**: 會寫 `nn.Module`、會跑 training loop。
- **線性代數**: 知道**鄰接矩陣 A** 是什麼,能用一句話解釋 `A @ X` 在做「鄰居特徵加總」。
- 知道 cross-entropy + softmax;會看 train/val accuracy 曲線。

**不需要**:不需要 spectral 理論、不需要 group theory(等變網路才需要,先跳過)。

## Message Passing 1 分鐘速成

GNN 一層做兩件事 (對節點 v):

```
1. 聚合:   m_v = AGG({ h_u : u ∈ N(v) })       # 收鄰居的訊息
2. 更新:   h_v' = UPDATE(h_v, m_v)              # 結合自己 + 鄰居
```

- `AGG` 可以是 sum / mean / max / attention,選擇決定不同架構:
  - GCN: 加權 mean (對稱歸一化)
  - GraphSAGE: mean / max / LSTM 三選一
  - GAT: attention 加權
  - GIN: sum (理論最強表達能力)
- `UPDATE` 通常是 MLP + 殘差。

**堆 L 層 = 看 L 跳鄰居**。太深會 over-smoothing(節點向量都被平均掉),實務常 2-4 層。

## 1 小時動手

```bash
pip install torch_geometric
```
跑 Cora dataset (引用網路 node classification, 2708 節點 7 類):

```python
from torch_geometric.datasets import Planetoid
from torch_geometric.nn import GCNConv
import torch.nn.functional as F, torch

dataset = Planetoid(root='/tmp/Cora', name='Cora')
data = dataset[0]

class GCN(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.c1 = GCNConv(dataset.num_features, 16)
        self.c2 = GCNConv(16, dataset.num_classes)
    def forward(self, x, edge_index):
        x = F.relu(self.c1(x, edge_index))
        x = F.dropout(x, training=self.training)
        return self.c2(x, edge_index)

model, opt = GCN(), torch.optim.Adam(GCN().parameters(), lr=0.01)
# 訓練 200 epoch 應該到 ~80% val accuracy
```

不到 50 行你就有一個能跑的 GNN。跑通後再回頭讀架構差異會更有感。

## 名詞速查

- **1-WL test (Weisfeiler-Leman)**: 圖同構演算法,GNN 表達能力上界由它決定,GIN 達到 1-WL 上限。
- **Homophily**: 「相似節點傾向相連」,GCN/GAT 預設假設;反例 (heterophily) 需要特殊架構 (H2GCN, FAGCN)。
- **PE (Positional Encoding)**: 圖沒有自然順序,需注入結構訊息 (Laplacian eigenvectors、Random Walk PE),Graph Transformer 必備。
- **Message Passing**: 上面的 AGG + UPDATE 範式,90% GNN 都在這框架內。
- **GCN / GraphSAGE / GAT / GIN**: 四大經典,分別代表 spectral、sampling、attention、injective aggregation 四條路線。
