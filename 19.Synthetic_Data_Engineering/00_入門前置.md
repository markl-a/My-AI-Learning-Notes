## 為何合成資料是 2024-2026 焦點(1 分鐘速成)
- **Data Wall**:Common Crawl 高品質中英文語料已被各家用盡,Epoch AI 估算公開文本將在 2026-2032 間耗盡。
- **版權壓力**:NYT v. OpenAI、Reddit / SO API 收費,scraped data 風險上升。
- **EU AI Act / 中國演算法備案**:訓練資料來源需可追溯,合成資料反而更乾淨。

## 代表案例(1 分鐘)
- **Phi-4**(MS, 2024):textbook-style 合成資料 + 嚴格過濾,14B 打敗 70B。
- **Nemotron-4 340B**(NVIDIA, 2024):對齊資料 **98% 為合成**,人類僅標 2%。
- **DeepSeek-R1**(2025):R1-Zero 用自舉式合成推理鏈,RL 訓練不靠人類示範。

## 名詞速查
| 詞 | 一句話 |
| --- | --- |
| Self-Instruct | 用 seed 任務讓 LLM 自己擴增指令(Wang 2022) |
| Evol-Instruct | 用 prompt 把簡單指令「進化」成複雜版本(WizardLM) |
| UltraFeedback | GPT-4 對多模型回答打分產出的偏好資料集 |
| Magpie | 只給 chat template 前綴,讓對齊過的模型「自言自語」吐 prompt |
| SemDeDup | embedding 近鄰去重 |
| MinHash / LSH | 字串 n-gram 近似去重,跑得快 |
