## 三層先決

主 README 假設你會這些。沒有的話先補:

1. **RL 基礎(PPO / reward model / advantage estimation)**——[../2.深入LLM模型工程與LLM運維/10.進階話題/強化學習與LLM整合指南.md](../2.深入LLM模型工程與LLM運維/10.進階話題/強化學習與LLM整合指南.md)。能講出 policy gradient、value baseline、KL penalty 三件事就夠。
2. **GRPO / RLAIF / verifier 風格 RL**——[../2.深入LLM模型工程與LLM運維/6.偏好對齊 (Alignment) 技術/GRPO_DAPO_RLVR_實戰.md](<../2.深入LLM模型工程與LLM運維/6.偏好對齊 (Alignment) 技術/GRPO_DAPO_RLVR_實戰.md>)。重點:DeepSeek-R1-Zero 跳過 SFT 用純 RL,需要的就是這套。
3. **Constitutional AI / 自我批評概念**——Anthropic 2022 paper《Constitutional AI: Harmlessness from AI Feedback》。一句話版:**用 AI 生 AI 的偏好標籤**,是「AI 改 AI」的最小可行單元。
4. **MCTS / evolutionary search 直覺**——讀 Sutton & Barto Ch. 8.7(MCTS)+ 任何一篇 genetic algorithm 介紹。重點是「LLM 提 prior,evaluator 提 signal,搜尋演算法協調」。

## 四個遞進層次 30 秒速成

| 層次 | 一句話 | 現狀 |
|---|---|---|
| 1. Automated AI research | AI 替代研究流程中某環節 | 已商用(Deep Research) |
| 2. Closed-loop discovery | AI 跑完整科研循環 | 狹義 demo 可行 |
| 3. Self-improvement | 模型用自身輸出改自己權重 | component-level 真實 |
| 4. RSI (Recursive Self-Improvement) | 改進的模型再改進模型,觸發飛輪 | **尚未觀察到** |

讀主 README 時要記住:**多數 demo 是 1-2 層,3 層碎片化存在,4 層還是 hypothesis**。

## 為何 2024-2026 是關鍵窗口

三個獨立訊號同時對齊:
- **Sakana AI Scientist v2** (2025-04):AI 寫的論文通過 ICLR workshop peer review。
- **AlphaEvolve** (2025-05):LLM + 演化搜尋把 Gemini 訓練 kernel 加速 23%,實際省下 ~1% 訓練時間——**最接近 RSI 的真實案例**。
- **DeepSeek-R1-Zero** (2025-01):純 RL bootstrap reasoning,無 SFT 也能湧現 self-verification——驗證「無人類資料的 self-play」可行於語言。

三家 frontier lab(Anthropic RSP v3、OpenAI Preparedness v2、DeepMind Frontier Safety)都已把 AI R&D 自動化列為需要監測的能力門檻。

## 30 分鐘動手

選一條:

- **路線 A(讀派)**:讀 Sakana《The AI Scientist-v2》(arXiv 2504.08066)abstract + AlphaEvolve 官方 blog(DeepMind 2025/05)。看完你會分得清「workshop 通過」與「真實 SOTA」差距。
- **路線 B(動手派)**:fork [`codelion/openevolve`](https://github.com/codelion/openevolve) (FunSearch / AlphaEvolve 開源復刻),跑 README 的 circle packing demo。觀察「LLM 變異 + evaluator 評分 + 演化挑選」三個 component 如何閉環。

## 名詞速查

- **RSI (Recursive Self-Improvement)**:模型改進的模型再改進模型的正反饋飛輪。
- **PRM (Process Reward Model)**:對推理「過程」打分而非僅結果,推理型 RL 主力。詳見 [../2.深入LLM模型工程與LLM運維/6.偏好對齊 (Alignment) 技術/PRM_訓練實作.md](<../2.深入LLM模型工程與LLM運維/6.偏好對齊 (Alignment) 技術/PRM_訓練實作.md>)。
- **Constitutional AI / RLAIF**:Anthropic 用 AI 生成偏好標籤,規避「人類標註者瓶頸」的對齊技術。
- **Tree search ideation**:在 idea 空間跑 MCTS/ToT,LLM 當 expansion operator——Sakana v2 核心技術。
- **Verifier-Solver loop**:solver 提解、verifier 評分、訊號回饋——AlphaProof / R1 數學能力的閉環結構。
- **Effective compute scale**:把演算法進步折算成等效 compute,Anthropic ASL-4 用「加速 35×/年」當觸發點。

## 重要警告:Hype 過濾器

本主題 hype 含量極高。請在閱讀任何「AI 自我改進」新聞時套用三道過濾器:

1. **看 evaluator 從哪來**:如果是 LLM-as-judge 自評,reward hacking 機率高;真實飛輪需要 distribution-外的 evaluator(holdout test、實驗室驗證、編譯器、SymPy)。
2. **看效益量級**:Sakana v2 是 **workshop level**(門檻低於 main conference),AlphaEvolve 是 **1% Gemini 訓練加速**——都不是 RSI,都是有意義的進步。混淆兩者的報導大多是 hype。
3. **看是否可重現**:frontier lab 內部 AI-for-AI 多半不公開;開源能跑通的多半是教學玩具。中間真實能力你只能從間接訊號(模型 release 節奏、kernel 文獻、招聘 JD)推斷。
