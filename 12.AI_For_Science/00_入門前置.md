## 為什麼這個 deep-dive 有門檻

AI4Science 是雙語言領域——既要會 ML(等變網路、SE(3)、diffusion),又要懂目標領域基本概念(蛋白質摺疊、晶格、第一性原理)。論文常省略領域常識,假設你已知道「為什麼 MSA 重要」「為什麼要 SE(3) 等變」。本檔目的:**用最短時間把雙邊基本詞彙打通**。

## 15 分鐘 quick start: Boltz-1 預測蛋白質結構

1. 安裝: `pip install boltz` (需要 ≥16GB VRAM 才能跑全長蛋白)
2. 準備輸入 fasta:
   ```
   >my_protein
   MKVLWAALLVTFLAGCQAKVEQAVETEPEPELRQQTEWQSGQRWELALGRFWDYLR
   ```
3. 執行: `boltz predict --use_msa_server my_protein.fasta`
   結果 `.cif` 可用 PyMOL 或 ChimeraX 開啟。

跑通後,你已親手經歷一遍「序列 → MSA → 結構」整條 pipeline,後面再讀 paper 就有錨點。

## 名詞速查

- **MSA (Multiple Sequence Alignment)**: 把同源蛋白序列對齊,演化資訊壓進矩陣,AlphaFold 之前最重要的訊號來源。
- **Homology**: 同源——序列相似度通常代表結構/功能相似,是預測的基礎假設。
- **PDB (Protein Data Bank)**: 蛋白質實驗結構的 ground truth 資料庫,訓練 label 來源。
- **SMILES**: 把分子寫成字串的 1D 表示法,例如水 = `O`、苯 = `c1ccccc1`,常用於 LLM 化學模型輸入。
- **DFT (Density Functional Theory)**: 量子化學基礎方法,算分子能量的「金本位」,但 O(N³) 慢——MLIP 就是用 ML 加速 DFT。
- **MLIP (Machine Learning Interatomic Potential)**: 用 NN 擬合勢能面,代表作 MACE、Allegro、Orb。
- **Ensemble forecast**: 氣象界傳統方法——跑很多次微擾初值取平均,GraphCast/Pangu/Aurora 等 ML 模型已能單次預測媲美 ensemble。
