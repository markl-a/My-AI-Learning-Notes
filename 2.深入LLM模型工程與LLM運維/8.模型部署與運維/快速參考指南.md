## GPU 記憶體計算

### 快速估算公式

```python
# 模型大小（GB）= 參數量（十億）× 精度位元組數
#
# 精度對照：
# - FP32: 4 bytes
# - FP16: 2 bytes
# - INT8: 1 byte
# - INT4: 0.5 bytes

# 總記憶體需求 = (模型 + KV Cache + Activation) × 1.2
```

### 常見模型記憶體需求

| 模型 | FP16 | INT8 | INT4 | 推薦 GPU |
|------|------|------|------|----------|
| 7B | 14 GB | 7 GB | 3.5 GB | T4 16GB |
| 13B | 26 GB | 13 GB | 6.5 GB | A10 24GB, V100 32GB |
| 30B | 60 GB | 30 GB | 15 GB | A100 40GB/80GB |
| 70B | 140 GB | 70 GB | 35 GB | 2x A100 80GB, A100 80GB (INT4) |

## 常用部署命令

### vLLM

```bash
# 啟動 OpenAI-compatible API 服務器
python -m vllm.entrypoints.openai.api_server \
    --model meta-llama/Llama-2-7b-chat-hf \
    --tensor-parallel-size 1 \
    --dtype float16 \
    --max-model-len 4096 \
    --gpu-memory-utilization 0.9 \
    --port 8000

# 多 GPU（4 張 GPU）
python -m vllm.entrypoints.openai.api_server \
    --model meta-llama/Llama-2-70b-hf \
    --tensor-parallel-size 4 \
    --dtype float16
```

### TensorRT-LLM

```bash
# 構建 TensorRT 引擎
python build.py \
    --model_dir ./Llama-2-7b-hf \
    --dtype float16 \
    --use_gpt_attention_plugin float16 \
    --use_gemm_plugin float16 \
    --max_batch_size 8 \
    --max_input_len 2048 \
    --max_output_len 512 \
    --output_dir ./trt_engines/llama2-7b

# 運行推理
python run.py \
    --engine_dir ./trt_engines/llama2-7b \
    --max_output_len 512
```

### Ollama

```bash
# 下載並運行模型
ollama pull llama2:7b
ollama run llama2:7b

# 啟動 API 服務
ollama serve

# 列出本地模型
ollama list

# 刪除模型
ollama rm llama2:7b
```

### Hugging Face Transformers

```bash
# 安裝
pip install transformers torch accelerate bitsandbytes

# Python 使用
python << EOF

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-chat-hf",

```

### GPU 優化

```bash
# 檢查 GPU 狀態
nvidia-smi

watch -n 1 nvidia-smi

python << EOF

```

### 模型量化

```python
# BitsAndBytes 4-bit 量化
from transformers import BitsAndBytesConfig

bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_use_double_quant=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_compute_dtype=torch.float16
)

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    quantization_config=bnb_config,
    device_map="auto"
)
```

### 批次大小選擇

```
單用戶即時：batch_size = 1
小規模服務：batch_size = 4-8
中規模服務：batch_size = 16-32
高吞吐量：batch_size = 64+ (使用連續批次)
```

### KV Cache 優化

```python
# 啟用 KV Cache
outputs = model.generate(
    input_ids,
    max_new_tokens=512,
    use_cache=True,  # 啟用 KV Cache
    past_key_values=past_kv  # 重用之前的 cache
)
```

## 故障排除

### GPU 問題

#### GPU 記憶體不足 (OOM)

```bash
# 檢查當前記憶體使用
nvidia-smi

# 解決方案：
# 1. 減小 batch_size
# 2. 使用量化（INT8/INT4）
# 3. 減小 max_length
# 4. 使用 gradient checkpointing

# 清理 GPU 記憶體
python -c "import torch; torch.cuda.empty_cache()"
```

#### GPU 未被檢測到

```bash
# 檢查 CUDA 是否可用
python -c "import torch; print(torch.cuda.is_available())"

# 檢查 NVIDIA 驅動
nvidia-smi

# 重新安裝 CUDA 工具包
# Ubuntu:
sudo apt-get install nvidia-cuda-toolkit

# 檢查 PyTorch CUDA 版本
python -c "import torch; print(torch.version.cuda)"
```

## 快速決策樹

### 選擇部署方案

```
流量 < 1K/天？
├─ 是 → 使用 Hugging Face Inference Endpoints 或 Replicate
└─ 否 → 流量 > 100K/天？
    ├─ 是 → 考慮本機部署
    └─ 否 → 使用雲端 GPU 實例
```

### 選擇推理框架

```
需要極致效能？
├─ 是 → 延遲敏感？
│   ├─ 是 → TensorRT-LLM
│   └─ 否 → vLLM
└─ 否 → 需要快速原型？
    ├─ 是 → Hugging Face Transformers
    └─ 否 → Text Generation Inference
```

### 選擇 GPU

```
模型大小 < 7B？
├─ 是 → T4 16GB
└─ 否 → 模型大小 < 13B？
    ├─ 是 → A10 24GB
    └─ 否 → 模型大小 < 30B？
        ├─ 是 → A100 40GB
        └─ 否 → 2x A100 80GB 或量化
```

## 常用 Python 程式碼片段

### 快速推理測試

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

# 載入模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-2-7b-chat-hf",
    torch_dtype=torch.float16,
    device_map="auto"
)
tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-2-7b-chat-hf")

# 推理
prompt = "What is AI?"
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
outputs = model.generate(**inputs, max_new_tokens=100)
result = tokenizer.decode(outputs[0], skip_special_tokens=True)
print(result)
```

### 記憶體監控

```python
import torch

def print_gpu_memory():
    if torch.cuda.is_available():
        for i in range(torch.cuda.device_count()):
            allocated = torch.cuda.memory_allocated(i) / 1024**3
            reserved = torch.cuda.memory_reserved(i) / 1024**3
            print(f"GPU {i}: Allocated: {allocated:.2f}GB, Reserved: {reserved:.2f}GB")

print_gpu_memory()
```

### API 客戶端測試

```python
import requests

# OpenAI-compatible API
def test_api(prompt, base_url="http://localhost:8000"):
    response = requests.post(
        f"{base_url}/v1/completions",
        json={
            "model": "meta-llama/Llama-2-7b-chat-hf",
            "prompt": prompt,
            "max_tokens": 200,
            "temperature": 0.7
        }
    )
    return response.json()

result = test_api("Hello, how are you?")
print(result)
```
