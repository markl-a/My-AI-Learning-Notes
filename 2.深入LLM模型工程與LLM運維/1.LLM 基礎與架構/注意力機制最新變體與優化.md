## 概述

注意力機制是 Transformer 的核心,其計算效率直接影響模型的訓練和推理性能。2024-2025年,多種創新的注意力變體被提出,旨在解決以下問題:

- **內存瓶頸**: 標準注意力的 O(n²) 內存復雜度
- **計算效率**: 減少 FLOPs 和加速推理
- **長序列處理**: 支持更長的上下文窗口
- **KV 快取優化**: 降低推理時的內存占用

### 標準注意力的挑戰

```python
# 標準 Multi-Head Attention
def standard_attention(Q, K, V):
    """
    Args:
        Q, K, V: [batch, heads, seq_len, head_dim]

    復雜度:
        時間: O(n²d)
        空間: O(n²)  # 主要瓶頸!
    """
    d_k = Q.size(-1)

    # 計算注意力分數 - 需要 O(n²) 內存
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(d_k)

    # Softmax
    attn_weights = F.softmax(scores, dim=-1)

    # 加權求和
    output = torch.matmul(attn_weights, V)

    return output
```

**問題:**
- 對於 seq_len=2048, heads=32: 需要存儲 32 × 2048 × 2048 = 134M 個浮點數
- 內存占用: ~536 MB (FP32) 每個樣本!

## Flash Attention 系列

### Flash Attention 1 (2022)

**核心思想:**
通過**分塊計算**和**重計算**策略,避免實體化完整的注意力矩陣。

#### 演算法原理

```python
def flash_attention_v1(Q, K, V, block_size=64):
    """Flash Attention V1 實現概念"""

    batch, heads, seq_len, head_dim = Q.shape

    # 初始化輸出
    O = torch.zeros_like(Q)
    l = torch.zeros(batch, heads, seq_len, 1)  # Normalizer
    m = torch.full((batch, heads, seq_len, 1), -float('inf'))  # Max value

    # 分塊處理
    num_blocks = (seq_len + block_size - 1) // block_size

    for i in range(num_blocks):
        # Q 塊
        q_start = i * block_size
        q_end = min((i + 1) * block_size, seq_len)
        Q_block = Q[:, :, q_start:q_end, :]

        for j in range(num_blocks):
            # KV 塊
            kv_start = j * block_size
            kv_end = min((j + 1) * block_size, seq_len)
            K_block = K[:, :, kv_start:kv_end, :]
            V_block = V[:, :, kv_start:kv_end, :]

            # 計算塊注意力分數
            scores_block = torch.matmul(Q_block, K_block.transpose(-2, -1))
            scores_block = scores_block / math.sqrt(head_dim)

            # 在線 softmax: 更新 max 和 normalizer
            m_new = torch.maximum(m[:, :, q_start:q_end], scores_block.max(dim=-1, keepdim=True).values)
            l_new = torch.exp(m[:, :, q_start:q_end] - m_new) * l[:, :, q_start:q_end] + \
                    torch.exp(scores_block - m_new).sum(dim=-1, keepdim=True)

            # 更新輸出
            O_block = torch.exp(m[:, :, q_start:q_end] - m_new) * O[:, :, q_start:q_end] + \
                      torch.matmul(torch.exp(scores_block - m_new), V_block)

            # 保存狀態
            O[:, :, q_start:q_end] = O_block
            l[:, :, q_start:q_end] = l_new
            m[:, :, q_start:q_end] = m_new

    # 最終歸一化
    O = O / l

    return O
```

**優勢:**
- 內存占用: O(n) vs O(n²)
- 速度提升: 2-4x
- 數學等價: 與標準注意力輸出相同

### Flash Attention 3 (2024)

**最新突破:**
1. **異步處理**: Warp 級別的異步執行
2. **低精度優化**: FP8 支持
3. **硬件適配**: 針對 H100 GPU 優化

**關鍵創新 - 三重緩衝 (Triple Buffering):**

```
GPU Warp 0    GPU Warp 1    GPU Warp 2
    ↓             ↓             ↓
[加載資料]    [計算]        [寫回結果]
```

**性能:**
- H100 GPU 上達到 740 TFLOPS (理論峰值 756 TFLOPS)
- 利用率: 98%+
- 相比 Flash Attention 2: 1.5-2x 加速

```python
# Flash Attention 3 使用 (PyTorch 2.4+)
import torch.nn.functional as F

def flash_attention_3(q, k, v, is_causal=True):
    """
    使用 PyTorch 2.4+ 內建的 Flash Attention 3

    Args:
        q, k, v: [batch, num_heads, seq_len, head_dim]

        enable_flash=True,
        enable_math=False,
        enable_mem_efficient=False

        output = F.scaled_dot_product_attention(
            q, k, v,
            attn_mask=None,
            dropout_p=0.0,
            is_causal=is_causal
        )

    return output
```

## Paged Attention

### 核心概念

Paged Attention 受虛擬內存啟發,將 KV 快取組織為頁面,實現高效的內存管理。

**問題背景:**
在自回歸生成中,KV 快取大小事先未知,導致:
- 內存碎片化
- 過度預分配浪費
- 動態調整開銷大

### 架構設計

```python
class PagedAttention:
    """Paged Attention 實現"""

    def __init__(self, page_size=16, num_pages=1024):
        """
        Args:
            page_size: 每頁可容納的 token 數
            num_pages: 總頁面數
        """
        self.page_size = page_size
        self.num_pages = num_pages

        # 物理頁面池
        self.k_cache_pool = torch.zeros(
            num_pages, page_size, num_heads, head_dim
        )
        self.v_cache_pool = torch.zeros(
            num_pages, page_size, num_heads, head_dim
        )

        # 頁表: sequence_id -> [頁面索引列表]
        self.page_tables = {}

        # 空閒頁面列表
        self.free_pages = list(range(num_pages))

    def allocate_pages(self, sequence_id, num_tokens):
        """為序列分配頁面"""

        num_pages_needed = (num_tokens + self.page_size - 1) // self.page_size

        allocated_pages = []
        for _ in range(num_pages_needed):
            if not self.free_pages:
                raise MemoryError("頁面池已滿")

            page_id = self.free_pages.pop(0)
            allocated_pages.append(page_id)

        self.page_tables[sequence_id] = allocated_pages

        return allocated_pages

    def free_pages(self, sequence_id):
        """釋放序列的頁面"""

        if sequence_id in self.page_tables:
            pages = self.page_tables[sequence_id]
            self.free_pages.extend(pages)
            del self.page_tables[sequence_id]

    def write_kv(self, sequence_id, position, k, v):
        """寫入 KV 快取"""

        # 計算頁面和頁內偏移
        page_idx = position // self.page_size
        offset = position % self.page_size

        # 獲取物理頁面 ID
        physical_page = self.page_tables[sequence_id][page_idx]

        # 寫入
        self.k_cache_pool[physical_page, offset] = k
        self.v_cache_pool[physical_page, offset] = v

    def read_kv(self, sequence_id, length):
        """讀取 KV 快取"""

        pages = self.page_tables[sequence_id]
        num_full_pages = length // self.page_size
        remainder = length % self.page_size

        k_list, v_list = [], []

        # 讀取完整頁面
        for i in range(num_full_pages):
            page_id = pages[i]
            k_list.append(self.k_cache_pool[page_id])
            v_list.append(self.v_cache_pool[page_id])

        # 讀取最後一頁
        if remainder > 0:
            page_id = pages[num_full_pages]
            k_list.append(self.k_cache_pool[page_id, :remainder])
            v_list.append(self.v_cache_pool[page_id, :remainder])

        # 拼接
        k_cache = torch.cat(k_list, dim=0)
        v_cache = torch.cat(v_list, dim=0)

        return k_cache, v_cache

    def compute_attention(self, q, sequence_id, length):
        """計算分頁注意力"""

        # 讀取 KV 快取
        k, v = self.read_kv(sequence_id, length)

        # 計算注意力
        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(q.size(-1))
        attn_weights = F.softmax(scores, dim=-1)
        output = torch.matmul(attn_weights, v)

        return output
```

### 優勢

1. **內存利用率**: 接近 100% (vs 傳統方法的 20-40%)
2. **動態分配**: 按需分配,無需預估
3. **共享機制**: 多序列可共享相同前綴的頁面

**應用: vLLM**

vLLM 使用 Paged Attention 實現了:
- 2-4x 吞吐量提升
- 顯著降低內存浪費

## Multi-Query Attention (MQA)

### 核心思想

所有注意力頭**共享同一組 K 和 V**,只有 Q 是多頭的。

```python
class MultiQueryAttention(nn.Module):
    """Multi-Query Attention"""

    def __init__(self, d_model, num_heads):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads

        # Q 是多頭的
        self.W_q = nn.Linear(d_model, d_model)

        # K, V 是單頭的
        self.W_k = nn.Linear(d_model, self.head_dim)
        self.W_v = nn.Linear(d_model, self.head_dim)

        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x):
        batch_size, seq_len, d_model = x.shape

        # 多頭 Q
        Q = self.W_q(x).view(batch_size, seq_len, self.num_heads, self.head_dim)
        Q = Q.transpose(1, 2)  # [batch, heads, seq, head_dim]

        # 單頭 K, V
        K = self.W_k(x).unsqueeze(1)  # [batch, 1, seq, head_dim]
        V = self.W_v(x).unsqueeze(1)  # [batch, 1, seq, head_dim]

        # 廣播 K, V 到所有頭
        K = K.expand(-1, self.num_heads, -1, -1)
        V = V.expand(-1, self.num_heads, -1, -1)

        # 計算注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.head_dim)
        attn_weights = F.softmax(scores, dim=-1)
        output = torch.matmul(attn_weights, V)

        # 合併頭
        output = output.transpose(1, 2).contiguous()
        output = output.view(batch_size, seq_len, d_model)

        # 輸出投影
        output = self.W_o(output)

        return output
```

### 優勢與權衡

**優勢:**
- KV 快取減少 num_heads 倍
- 推論速度提升 1.3-1.5x
- 內存占用大幅降低

**權衡:**
- 模型表達能力略降
- 訓練質量可能下降 1-2%

**應用模型:**
- PaLM
- Falcon
- StarCoder

## Grouped-Query Attention (GQA)

### 核心思想

MQA 和標準多頭注意力的折中: 將頭分組,每組共享 K, V。

```python
class GroupedQueryAttention(nn.Module):
    """Grouped-Query Attention"""

    def __init__(self, d_model, num_heads, num_kv_heads):
        super().__init__()
        self.num_heads = num_heads
        self.num_kv_heads = num_kv_heads
        self.head_dim = d_model // num_heads

        assert num_heads % num_kv_heads == 0
        self.num_queries_per_kv = num_heads // num_kv_heads

        # Q 投影 (全部頭)
        self.W_q = nn.Linear(d_model, d_model)

        # K, V 投影 (分組)
        self.W_k = nn.Linear(d_model, num_kv_heads * self.head_dim)
        self.W_v = nn.Linear(d_model, num_kv_heads * self.head_dim)

        self.W_o = nn.Linear(d_model, d_model)

    def forward(self, x):
        batch_size, seq_len, d_model = x.shape

        # Q: [batch, num_heads, seq, head_dim]
        Q = self.W_q(x).view(batch_size, seq_len, self.num_heads, self.head_dim)
        Q = Q.transpose(1, 2)

        # K, V: [batch, num_kv_heads, seq, head_dim]
        K = self.W_k(x).view(batch_size, seq_len, self.num_kv_heads, self.head_dim)
        K = K.transpose(1, 2)

        V = self.W_v(x).view(batch_size, seq_len, self.num_kv_heads, self.head_dim)
        V = V.transpose(1, 2)

        # 重複 K, V 以匹配 Q 的頭數
        K = K.repeat_interleave(self.num_queries_per_kv, dim=1)
        V = V.repeat_interleave(self.num_queries_per_kv, dim=1)

        # 計算注意力
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.head_dim)
        attn_weights = F.softmax(scores, dim=-1)
        output = torch.matmul(attn_weights, V)

        # 合併頭
        output = output.transpose(1, 2).contiguous()
        output = output.view(batch_size, seq_len, d_model)
        output = self.W_o(output)

        return output
```

### 配置示例

```python
# LLaMA 2 配置
config = {
    'num_heads': 32,
    'num_kv_heads': 8,  # 每 4 個 Q 頭共享 1 組 KV
}

# Mistral 7B 配置

    'num_heads': 32,
    'num_kv_heads': 8,
}
```

| 方法 | KV 快取大小 | 推論速度 | 模型品質 |
|------|------------|---------|---------|
| Multi-Head (MHA) | 100% | 1.0x | 100% |
| Grouped-Query (GQA) | 25% (8組) | 1.3-1.4x | 99% |

## Sliding Window Attention

### 核心概念

限制每個 token 只關注其前面的 **W** 個 token,而不是全部。

```python
def sliding_window_attention(Q, K, V, window_size=256):
    """
    滑動窗口注意力

    Args:
        Q, K, V: [batch, heads, seq_len, head_dim]
        window_size: 窗口大小
    """
    batch, heads, seq_len, head_dim = Q.shape

    # 計算完整的注意力分數
    scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(head_dim)

    # 建立滑動窗口掩碼
    mask = torch.ones(seq_len, seq_len, dtype=torch.bool)
    for i in range(seq_len):
        # 允許看到 [i-window_size+1, i] 的範圍
        start = max(0, i - window_size + 1)
        mask[i, start:i+1] = False

    # 應用掩碼
    scores = scores.masked_fill(mask.unsqueeze(0).unsqueeze(0), float('-inf'))

    # Softmax 和輸出
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)

    return output
```

### 優化實現: Sparse Attention

```python
from torch.sparse import sparse_coo_tensor

def sparse_sliding_window_attention(Q, K, V, window_size=256):
    """使用稀疏張量的滑動窗口注意力"""

    batch, heads, seq_len, head_dim = Q.shape

    # 只計算窗口內的注意力
    outputs = []

    for i in range(seq_len):
        start = max(0, i - window_size + 1)
        end = i + 1

        # 當前 token 的 Q
        q_i = Q[:, :, i:i+1, :]  # [batch, heads, 1, head_dim]

        # 窗口內的 K, V
        k_window = K[:, :, start:end, :]
        v_window = V[:, :, start:end, :]

        # 計算注意力
        scores = torch.matmul(q_i, k_window.transpose(-2, -1)) / math.sqrt(head_dim)
        attn_weights = F.softmax(scores, dim=-1)
        output_i = torch.matmul(attn_weights, v_window)

        outputs.append(output_i)

    # 拼接所有輸出
    output = torch.cat(outputs, dim=2)

    return output
```

### 應用

**Mistral 7B:**
- 窗口大小: 4096
- 滑動窗口 + GQA
- 實現長序列處理的高效推理

## RoPE - 旋轉位置編碼

### 核心原理

RoPE (Rotary Position Embedding) 通過**旋轉變換**注入位置資訊,具有優秀的外推能力。

### 數學表示

對於位置 `m` 的向量 `x`,應用旋轉矩陣:

```
RoPE(x, m) = [
  [cos(mθ₁)  -sin(mθ₁)] [x₁]
  [sin(mθ₁)   cos(mθ₁)] [x₂]
  [cos(mθ₂)  -sin(mθ₂)] [x₃]
  [sin(mθ₂)   cos(mθ₂)] [x₄]
  ...
]
```

其中 `θᵢ = 10000^(-2i/d)`

### 實現

```python
class RotaryPositionEmbedding(nn.Module):
    """RoPE 實現"""

    def __init__(self, dim, max_seq_len=2048, base=10000):
        super().__init__()
        self.dim = dim
        self.max_seq_len = max_seq_len
        self.base = base

        # 預計算頻率
        inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer('inv_freq', inv_freq)

        # 預計算位置編碼
        self._init_rope_cache(max_seq_len)

    def _init_rope_cache(self, max_seq_len):
        """初始化 RoPE 快取"""

        # 位置索引
        positions = torch.arange(max_seq_len)

        # 計算角度
        freqs = torch.outer(positions, self.inv_freq).float()

        # 生成 cos 和 sin
        emb = torch.cat((freqs, freqs), dim=-1)
        self.register_buffer('cos_cached', emb.cos(), persistent=False)
        self.register_buffer('sin_cached', emb.sin(), persistent=False)

    def rotate_half(self, x):
        """旋轉一半維度"""
        x1, x2 = x.chunk(2, dim=-1)
        return torch.cat((-x2, x1), dim=-1)

    def forward(self, q, k, positions=None):
        """
        應用 RoPE

        Args:
            q, k: [batch, heads, seq_len, head_dim]
            positions: 位置索引 (可選)
        """
        seq_len = q.size(2)

        if positions is None:
            positions = torch.arange(seq_len, device=q.device)

        # 獲取對應位置的 cos/sin
        cos = self.cos_cached[positions].unsqueeze(0).unsqueeze(0)
        sin = self.sin_cached[positions].unsqueeze(0).unsqueeze(0)

        # 應用旋轉
        q_embed = (q * cos) + (self.rotate_half(q) * sin)
        k_embed = (k * cos) + (self.rotate_half(k) * sin)

        return q_embed, k_embed

# 使用示例
rope = RotaryPositionEmbedding(dim=64, max_seq_len=2048)

Q = torch.randn(2, 8, 512, 64)  # [batch, heads, seq, head_dim]
K = torch.randn(2, 8, 512, 64)

Q_rope, K_rope = rope(Q, K)
```

### 優勢

1. **相對位置建模**: 自然編碼相對位置關係
2. **外推能力**: 可處理超出訓練長度的序列
3. **無額外參數**: 不增加模型參數
4. **長上下文友好**: 支持長序列擴展

**應用模型:**
- LLaMA 系列
- GPT-NeoX

## ALiBi - 線性偏置注意力

### 核心思想

在注意力分數上添加**線性遞減的偏置**,距離越遠偏置越負。

### 公式

```
softmax(Q·Kᵀ/√d + m·[-(i-j)])
```

其中:
- `m`: 頭特定的斜率 (head-specific slope)
- `i-j`: token 之間的距離

### 實現

```python
class ALiBiAttention(nn.Module):
    """ALiBi (Attention with Linear Biases) 實現"""

    def __init__(self, num_heads, max_seq_len=2048):
        super().__init__()
        self.num_heads = num_heads
        self.max_seq_len = max_seq_len

        # 計算每個頭的斜率
        slopes = self._get_slopes(num_heads)
        self.register_buffer('slopes', slopes)

        # 預計算偏置矩陣
        alibi = self._build_alibi_tensor(max_seq_len, slopes)
        self.register_buffer('alibi', alibi)

    def _get_slopes(self, num_heads):
        """計算頭斜率"""

        # 幾何序列: 2^(-8/n), 2^(-16/n), ..., 2^(-8)
        def get_slopes_power_of_2(n):
            start = 2 ** (-(2 ** -(math.log2(n) - 3)))
            ratio = start
            return [start * (ratio ** i) for i in range(n)]

        # 處理非 2 的冪次
        if math.log2(num_heads).is_integer():
            slopes = get_slopes_power_of_2(num_heads)
        else:
            closest_power = 2 ** math.floor(math.log2(num_heads))
            slopes = get_slopes_power_of_2(closest_power) + \
                     get_slopes_power_of_2(2 * closest_power)[0::2][:num_heads - closest_power]

        return torch.tensor(slopes).float()

    def _build_alibi_tensor(self, max_seq_len, slopes):
        """構建 ALiBi 偏置張量"""

        # 建立距離矩陣: [i - j]
        positions = torch.arange(max_seq_len)
        distances = positions.unsqueeze(0) - positions.unsqueeze(1)

        # 應用斜率: m * [-(i-j)]
        # [num_heads, max_seq_len, max_seq_len]
        alibi = slopes.unsqueeze(-1).unsqueeze(-1) * (-distances.abs().float())

        return alibi

    def forward(self, Q, K, V):
        """
        Args:
            Q, K, V: [batch, num_heads, seq_len, head_dim]
        """
        batch, num_heads, seq_len, head_dim = Q.shape

        # 計算標準注意力分數
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(head_dim)

        # 添加 ALiBi 偏置
        alibi_bias = self.alibi[:num_heads, :seq_len, :seq_len]
        scores = scores + alibi_bias.unsqueeze(0)

        # Softmax 和輸出
        attn_weights = F.softmax(scores, dim=-1)
        output = torch.matmul(attn_weights, V)

        return output

# 使用示例
alibi_attn = ALiBiAttention(num_heads=8, max_seq_len=2048)

Q = torch.randn(2, 8, 512, 64)
K = torch.randn(2, 8, 512, 64)
V = torch.randn(2, 8, 512, 64)

output = alibi_attn(Q, K, V)
```

- Flash Attention 2

**大型模型 (>10B):**

## 實作技巧

### 1. 混合使用多種優化

```python
class OptimizedAttention(nn.Module):
    """綜合優化的注意力層"""

    def __init__(self, config):
        super().__init__()
        self.config = config

        # GQA
        self.gqa = GroupedQueryAttention(
            d_model=config.d_model,
            num_heads=config.num_heads,
            num_kv_heads=config.num_kv_heads
        )

        # RoPE
        self.rope = RotaryPositionEmbedding(
            dim=config.head_dim,
            max_seq_len=config.max_seq_len
        )

        # Flash Attention
        self.use_flash = config.use_flash_attention

    def forward(self, x, use_cache=False, past_kv=None):
        # 1. 應用 GQA 投影
        Q, K, V = self.gqa.project(x)

        # 2. 應用 RoPE
        Q, K = self.rope(Q, K)

        # 3. KV 快取 (推理時)
        if use_cache and past_kv is not None:
            K = torch.cat([past_kv[0], K], dim=2)
            V = torch.cat([past_kv[1], V], dim=2)

        # 4. 計算注意力
        if self.use_flash and self.training:
            output = flash_attention_3(Q, K, V, is_causal=True)
        else:
            output = self.gqa.compute_attention(Q, K, V)

        # 5. 返回輸出和快取
        new_kv = (K, V) if use_cache else None

        return output, new_kv
```

### 2. 動態選擇策略

```python
def select_attention_mechanism(seq_len, batch_size, is_training):
    """根據場景選擇注意力機制"""

    if is_training:
        # 訓練時優先 Flash Attention
        if torch.cuda.is_available():
            return "flash_attention_3"
        else:
            return "flash_attention_2"
    else:
        # 推理時根據批次大小選擇
        if batch_size > 8:
            # 高吞吐量場景
            return "paged_attention"
        else:
            # 低延遲場景
            return "flash_attention_2"
```
