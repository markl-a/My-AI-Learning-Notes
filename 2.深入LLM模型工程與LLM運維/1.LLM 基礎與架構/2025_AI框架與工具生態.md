## 一、LLM 應用開發框架

### 1. LangChain 與 LangGraph

**LangChain 核心特性：**
- **定位**：開源 Python 框架，構建生產級 LLM 應用和 Agent
- **生態系統**：最大的 LLM 工具、組件和集成生態系統
- **適用場景**：簡單編排任務

**LangGraph 革新：**
- **架構**：在 LangChain 之上構建，用於複雜的 Agent 工作流
- **核心概念**：將 Agent 推理步驟表示為有向無環圖（DAG）中的節點
- **優勢**：
  - 支持複雜的狀態管理
  - 支持分支、循環
  - 支持多 Agent 協作

**官方建議：**
- 簡單編排 → 使用 LangChain
- 複雜狀態管理、分支、循環、多 Agent → 使用 LangGraph

**使用示例：**
```python
from langgraph.graph import StateGraph, END
from typing import TypedDict, Annotated
import operator

# 定義狀態
class AgentState(TypedDict):
    messages: Annotated[list, operator.add]
    next_step: str

# 創建圖
workflow = StateGraph(AgentState)

# 添加節點
def research_node(state):
    # 執行研究任務
    return {"messages": [state["messages"][-1] + " - researched"], "next_step": "write"}

def write_node(state):
    # 執行寫作任務
    return {"messages": [state["messages"][-1] + " - written"], "next_step": END}

workflow.add_node("research", research_node)
workflow.add_node("write", write_node)

# 設置入口點和邊
workflow.set_entry_point("research")
workflow.add_edge("research", "write")
workflow.add_edge("write", END)

# 編譯並運行
app = workflow.compile()
result = app.invoke({"messages": ["Start task"], "next_step": "research"})
```

### 2. LlamaIndex

**核心定位：**
- **數據為中心**：專為使用組織內部數據的 RAG 和 Agent 應用設計
- **原名**：GPT Index（Meta 開發）
- **核心優勢**：將語言模型連接到數據

**主要功能：**
- **數據連接器**：數十個開箱即用的數據連接器
- **解析能力**：PDF 到 HTML 解析、元數據提取、分塊
- **RAG 專長**：在檢索增強生成和知識訪問方面表現出色

**適用場景：**
- 輕量級、直接的 RAG 應用
- 企業數據查詢與分析
- 知識庫構建

**使用示例：**
```python
from llama_index import VectorStoreIndex, SimpleDirectoryReader

# 加載文檔
documents = SimpleDirectoryReader('data').load_data()

# 創建索引
index = VectorStoreIndex.from_documents(documents)

# 查詢
query_engine = index.as_query_engine()
response = query_engine.query("What is the main topic of these documents?")
print(response)
```

**企業案例：**
- **金融服務**：處理監管合規工作流，顯著縮短文檔處理時間
- **大量文檔管理**：高效管理和查詢企業文檔庫

### 3. Semantic Kernel

**特點：**
- **微軟開發**：與 .NET 生態系統深度整合
- **通用框架**：支持良好的多語言框架
- **適用場景**：企業級 .NET 應用

## 二、AI Agent 框架（2025年12大框架）

### 1. CrewAI

**特點：**
- **多 Agent 編排**：專注於具有角色/任務抽象的多 Agent 協作
- **角色定義**：為每個 Agent 分配特定角色和任務
- **協作機制**：Agent 之間的工作流協調

### 2. AutoGen

**特點：**
- **微軟研究院**：由微軟開發的多 Agent 框架
- **會話式 AI**：支持多個 Agent 之間的對話協作
- **應用廣泛**：適合複雜的多 Agent 場景

### 3. Lyzr

**定位：**
- **企業級**：面向企業解決方案和工作流自動化
- **全棧框架**：自主 AI Agent 完整解決方案
- **工作流自動化**：簡化企業業務流程

### 4. Crawl4AI

**特點：**
- **網頁抓取**：AI 驅動的網頁抓取和數據提取
- **開源工具**：輕量級且易於使用
- **數據收集**：為 AI 應用提供數據源

### 5. Stagehand

**特點：**
- **任務型**：輕量級的任務型 AI Agent 框架
- **簡單高效**：快速部署和執行

### 6. 其他重要框架

- **Haystack**：面向 NLP 的端到端框架
- **BabyAGI**：輕量級自主任務管理系統
- **AgentGPT**：瀏覽器中的自主 AI Agent
- **Superagent**：構建、部署和管理 AI Agent 的平台
- **Rasa**：對話式 AI 框架
- **Botpress**：企業級聊天機器人平台

## 三、AI 推理服務框架

### 1. vLLM

**核心優勢：**
- **高吞吐量**：業界領先的吞吐量性能
- **PagedAttention**：高效的 KV 緩存管理
- **持續批處理**：Continuous Batching 技術

**性能表現：**
- 在 100 並發請求時達到 **4,741 tokens/秒**
- 首個 token 生成速度最快
- 適合高吞吐量場景

**基準測試（Llama 3.1）：**
```
並發數    吞吐量        TTFT (首token時間)
10       2,341 t/s     150ms
50       3,892 t/s     280ms
100      4,741 t/s     420ms
```

**使用示例：**
```python
from vllm import LLM, SamplingParams

# 初始化模型
llm = LLM(model="meta-llama/Llama-3.1-8B")

# 設置採樣參數
sampling_params = SamplingParams(temperature=0.8, top_p=0.95)

# 生成
prompts = ["Hello, my name is", "The capital of France is"]
outputs = llm.generate(prompts, sampling_params)

for output in outputs:
    print(output.outputs[0].text)
```

### 2. SGLang

**核心創新 - RadixAttention：**
- **KV 緩存優化**：將用戶提示保存在 KV 緩存中
- **提示重用**：當提示部分重複時提升性能
- **聊天場景優化**：特別適合對話應用

**2025年重大更新：**
- **DeepSeek 優化**：首日支持 DeepSeek V3/R1 模型
- **多 GPU 支持**：NVIDIA 和 AMD GPU 全面支持
- **DeepSeek 專屬優化**：針對性能調優

**適用場景：**
- Agent 系統
- 工具鏈
- 重度 RAG 系統
- KV 緩存重用場景

**性能優勢：**
- 通過 RadixAttention 實現大幅性能提升
- 在聊天場景中表現尤為出色

### 3. TensorRT-LLM

**NVIDIA 優化：**
- **硬件深度優化**：針對 NVIDIA GPU 的深度優化
- **B200 GPU 領先**：在最新硬件上性能最佳
- **低並發優勢**：單用戶應用性能突出

**性能表現：**
- 在 B200 GPU 上，所有指標均超越 SGLang 和 vLLM
- 最大化硬件效率
- 低並發場景的首選

**適用場景：**
- 單用戶應用
- 需要最大化硬件效率的場景
- NVIDIA 生態系統

**基準對比（B200 GPU）：**
```
框架           吞吐量    TTFT    GPU利用率
TensorRT-LLM   5,234    95ms    94%
SGLang         4,856    112ms   89%
vLLM           4,741    105ms   91%
```

### 4. NVIDIA Dynamo（GTC 2025 發布）

**兼容性：**
- PyTorch

**特點：**
- 針對推理模型（Reasoning Models）優化
- 支持大規模分佈式部署
- 與現有工具完美集成

### 5. Hugging Face TGI (Text Generation Inference)

**多後端支持（2025）：**
- **TensorRT-LLM 後端**

- **原生 TGI 後端**

**特點：**
- 靈活的後端選擇
- Hugging Face 生態系統整合
