## 多模態概述

### 什麼是多模態？

多模態模型能夠理解和生成多種類型的資料：

```
文字 ←→ 圖像 ←→ 音頻 ←→ 影片
```

**核心挑戰**：
1. **模態對齊**：將不同模態映射到共同語義空間
2. **資訊融合**：有效整合來自不同模態的資訊
3. **生成能力**：支持跨模態生成

### 發展歷程

```
2021: CLIP, DALL-E
  ↓
2022: Flamingo, BLIP
  ↓
2023: GPT-4V, LLaVA
  ↓
2024: GPT-4o, Gemini 1.5 Pro, Claude 3.5
  ↓
2025: 實時多模態、具身智能
```

### 主要模態

| 模態 | 特點 | 挑戰 |
|------|------|------|
| **文字** | 離散、結構化 | 語義理解 |
| **圖像** | 連續、空間資訊 | 高維、計算密集 |
| **音頻** | 時序、連續 | 時間對齊 |
| **影片** | 時空資訊 | 資料量大 |

## CLIP: 視覺-語言對齊

### 核心思想

CLIP (Contrastive Language-Image Pre-training) 通過對比學習將圖像和文字映射到同一語義空間。

### 架構

```
圖像 → Image Encoder → Image Embedding ─┐
                                          ├─→ 對比學習
文字 → Text Encoder → Text Embedding ────┘
```

**組件**：
1. **Image Encoder**：Vision Transformer (ViT) 或 ResNet
2. **Text Encoder**：Transformer
3. **對比損失**：InfoNCE

### 訓練方法

#### 對比學習

給定 N 對 (image, text) 樣本：

**目標**：
- 匹配的 (image, text) 對：相似度高
- 不匹配的對：相似度低

**損失函式**：

$$
\mathcal{L} = -\frac{1}{N} \sum_{i=1}^{N} \log \frac{\exp(\text{sim}(I_i, T_i) / \tau)}{\sum_{j=1}^{N} \exp(\text{sim}(I_i, T_j) / \tau)}
$$

其中：
- $I_i$: 第 i 個圖像嵌入
- $T_i$: 第 i 個文字嵌入
- $\text{sim}$: 餘弦相似度
- $\tau$: 溫度參數

#### 視覺化

```
       文字1  文字2  文字3  文字4
圖像1   0.9   0.1   0.2   0.1   ← 對角線應該最大
圖像2   0.1   0.8   0.1   0.2
圖像3   0.2   0.1   0.9   0.1
圖像4   0.1   0.2   0.1   0.85
```

### CLIP 的能力

1. **Zero-shot 分類**
   ```python
   # 無需訓練，直接分類
   categories = ["dog", "cat", "bird", "fish"]
   prompts = [f"a photo of a {c}" for c in categories]
   # 比較圖像與所有提示的相似度
   ```

2. **圖像檢索**
   ```python
   # 文字搜索圖像
   query = "a sunset over the ocean"
   # 找到最相似的圖像
   ```

3. **多模態嵌入**
   ```python
   # 將圖像和文字映射到同一空間
   img_emb = clip.encode_image(image)
   txt_emb = clip.encode_text(text)
   similarity = cosine_similarity(img_emb, txt_emb)
   ```

### CLIP 的限制

- **無法生成圖像**：只能理解，不能建立
- **缺乏細粒度理解**：難以識別小物體、複雜關係
- **OCR 能力弱**：不擅長讀取文字

## LLaVA: 視覺指令調優

### 設計理念

LLaVA (Large Language and Vision Assistant) 將視覺資訊作為 LLM 的輸入，實現視覺問答。

### 架構

```
圖像 → Vision Encoder → 視覺特徵 → Projection Layer → 視覺 Token
                                                          ↓
文字 → Tokenizer → 文字 Token ─────────────────────→ 拼接 → LLM → 回答
```

**核心組件**：

1. **Vision Encoder**：預訓練的 CLIP ViT
2. **Projection Layer**：將視覺特徵映射到 LLM 的嵌入空間
3. **LLM**：Vicuna, LLaMA 等

### 訓練流程

#### 階段 1: 預訓練（對齊）

**目標**：學習視覺-語言映射

**資料**：圖像-標題對（CC3M, COCO）

**方法**：
- 凍結 Vision Encoder 和 LLM
- 只訓練 Projection Layer

**任務**：給定圖像，生成描述

```
Input: [Image] Describe this image briefly.
Output: A dog playing in the park.
```

#### 階段 2: 指令微調

**目標**：提升指令跟隨能力

**資料**：多樣化的視覺問答資料

**方法**：
- 凍結 Vision Encoder
- 微調 Projection Layer 和 LLM

**任務類型**：
- 詳細描述
- 視覺推理
- OCR 和文字識別
- 知識型問答

**示例**：
```
Input: [Image] What is the person in the image doing? Think step by step.
Output: Let me analyze this image:
1. I can see a person wearing sports attire
2. They are holding a tennis racket
3. The setting appears to be a tennis court
Therefore, the person is playing tennis.
```

### LLaVA 的優勢

1. **簡單高效**：架構簡潔，易於實現
2. **強大的推理能力**：繼承 LLM 的推理能力
3. **可擴展**：容易適配不同的 LLM 和 Vision Encoder

### LLaVA 變體

| 模型 | 特點 |
|------|------|
| **LLaVA-1.5** | 改進訓練流程，更好的性能 |
| **LLaVA-NeXT** | 支持高分辨率圖像 |
| **LLaVA-Video** | 擴展到影片理解 |
| **MobileVLM** | 輕量化版本，適合移動端 |

## 多模態架構設計

### 1. Early Fusion（早期融合）

在輸入層融合不同模態：

```
Image → Encoder ─┐
                  ├→ Concat → Unified Model → Output
Text → Encoder ──┘
```

**優點**：簡單、端到端訓練
**缺點**：難以處理缺失模態

### 2. Late Fusion（晚期融合）

分別處理後再融合：

```
Image → Image Model → Image Output ─┐
                                      ├→ Fusion → Final Output
Text → Text Model → Text Output ────┘
```

**優點**：靈活、模塊化
**缺點**：可能錯過跨模態交互

### 3. Cross-Modal Attention（跨模態注意力）

通過注意力機制融合：

```
Image Features ←─ Cross-Attention ←→ Text Features
```

**實現**：
```python
class CrossModalAttention(nn.Module):
    def forward(self, image_features, text_features):
        # Text 作為 Query，Image 作為 Key/Value
        attended_image = attention(
            query=text_features,
            key=image_features,
            value=image_features
        )
        return attended_image
```

### 4. Adapter（適配器層）

將視覺特徵映射到語言模型空間：

```
Visual Encoder → [Adapter] → LLM Token Space
```

**LLaVA 使用的方法**：
```python
class VisionAdapter(nn.Module):
    def __init__(self, vision_dim, llm_dim):
        super().__init__()
        self.linear = nn.Linear(vision_dim, llm_dim)

    def forward(self, vision_features):
        # vision_features: (batch, num_patches, vision_dim)
        # output: (batch, num_patches, llm_dim)
        return self.linear(vision_features)
```

## Python 實作範例

### 1. 使用 CLIP 進行圖像分類

```python
import torch
import clip
from PIL import Image

# 載入模型
device = "cuda" if torch.cuda.is_available() else "cpu"
model, preprocess = clip.load("ViT-B/32", device=device)

# 準備圖像
image = preprocess(Image.open("photo.jpg")).unsqueeze(0).to(device)

# 準備文字
categories = ["dog", "cat", "bird", "fish", "horse"]
text_inputs = torch.cat([clip.tokenize(f"a photo of a {c}") for c in categories]).to(device)

# 計算特徵
with torch.no_grad():
    image_features = model.encode_image(image)
    text_features = model.encode_text(text_inputs)

    # 歸一化
    image_features /= image_features.norm(dim=-1, keepdim=True)
    text_features /= text_features.norm(dim=-1, keepdim=True)

    # 計算相似度
    similarity = (100.0 * image_features @ text_features.T).softmax(dim=-1)

# 顯示結果
print("分類結果:")
for i, category in enumerate(categories):
    print(f"{category}: {similarity[0, i].item()*100:.2f}%")

# 預測
predicted_idx = similarity.argmax().item()
print(f"\n預測: {categories[predicted_idx]}")
```

### 3. CLIP + LLM 組合應用

```python
import openai
import clip
import torch
from PIL import Image

class VisionLLMAssistant:
    """結合 CLIP 和 GPT 的視覺助手"""

    def __init__(self, openai_api_key):
        self.clip_model, self.preprocess = clip.load("ViT-L/14")
        openai.api_key = openai_api_key

    def understand_image(self, image_path, query):
        """理解圖像並回答問題"""

        # 1. 使用 CLIP 生成圖像描述
        image = self.preprocess(Image.open(image_path)).unsqueeze(0)

        # 預定義的描述模板
        descriptions = [
            "a photo of a person",
            "a landscape photo",
            "a photo of an animal",
            "a photo of food",
            "a photo of a building",
            "a photo of a vehicle",
            "a photo of indoor scene",
            "a photo of outdoor scene",
        ]

        text_inputs = torch.cat([clip.tokenize(desc) for desc in descriptions])

        with torch.no_grad():
            image_features = self.clip_model.encode_image(image)
            text_features = self.clip_model.encode_text(text_inputs)

            image_features /= image_features.norm(dim=-1, keepdim=True)
            text_features /= text_features.norm(dim=-1, keepdim=True)

            similarity = (100.0 * image_features @ text_features.T).softmax(dim=-1)

        # 找到最相關的描述
        top_idx = similarity.topk(3).indices[0].tolist()
        top_descriptions = [descriptions[i] for i in top_idx]

        # 2. 使用 GPT 生成詳細回答
        context = f"This image appears to be: {', '.join(top_descriptions)}"

        response = openai.ChatCompletion.create(
            model="gpt-4",
            messages=[
                {"role": "system", "content": "You are a helpful vision assistant."},
                {"role": "user", "content": f"{context}\n\nUser question: {query}"}
            ]
        )

        return response.choices[0].message.content

# 使用
assistant = VisionLLMAssistant(openai_api_key="your-api-key")
answer = assistant.understand_image("photo.jpg", "What can you tell me about this image?")
print(answer)
```

### 4. 多模態檢索系統

```python
import numpy as np
import faiss
from typing import List, Union
from PIL import Image

class MultiModalSearch:
    """多模態搜索引擎"""

    def __init__(self):
        self.clip_model, self.preprocess = clip.load("ViT-B/32")
        self.index = None
        self.image_paths = []

    def build_index(self, image_paths: List[str]):
        """構建圖像索引"""
        print(f"為 {len(image_paths)} 張圖像建立索引...")

        embeddings = []
        for img_path in image_paths:
            image = self.preprocess(Image.open(img_path)).unsqueeze(0)

            with torch.no_grad():
                features = self.clip_model.encode_image(image)
                features /= features.norm(dim=-1, keepdim=True)

            embeddings.append(features.cpu().numpy())

        # 使用 FAISS 建立索引
        embeddings = np.vstack(embeddings).astype('float32')
        dimension = embeddings.shape[1]

        self.index = faiss.IndexFlatIP(dimension)  # 內積相似度
        self.index.add(embeddings)
        self.image_paths = image_paths

        print("索引建立完成！")

    def search_by_text(self, query: str, top_k: int = 5):
        """文字搜索圖像"""
        text_input = clip.tokenize([query])

        with torch.no_grad():
            text_features = self.clip_model.encode_text(text_input)
            text_features /= text_features.norm(dim=-1, keepdim=True)

        query_embedding = text_features.cpu().numpy().astype('float32')

        # 搜索
        distances, indices = self.index.search(query_embedding, top_k)

        results = []
        for dist, idx in zip(distances[0], indices[0]):
            results.append({
                'image_path': self.image_paths[idx],
                'similarity': float(dist)
            })

        return results

    def search_by_image(self, image_path: str, top_k: int = 5):
        """以圖搜圖"""
        image = self.preprocess(Image.open(image_path)).unsqueeze(0)

        with torch.no_grad():
            image_features = self.clip_model.encode_image(image)
            image_features /= image_features.norm(dim=-1, keepdim=True)

        query_embedding = image_features.cpu().numpy().astype('float32')

        distances, indices = self.index.search(query_embedding, top_k)

        results = []
        for dist, idx in zip(distances[0], indices[0]):
            results.append({
                'image_path': self.image_paths[idx],
                'similarity': float(dist)
            })

        return results

# 使用示例
"""
search = MultiModalSearch()
search.build_index(["img1.jpg", "img2.jpg", "img3.jpg", ...])

# 文字搜索
results = search.search_by_text("sunset over ocean")
for r in results:
    print(f"{r['image_path']}: {r['similarity']:.4f}")

# 以圖搜圖
results = search.search_by_image("query.jpg")
```

```python
    def get_history(self):

        return self.conversation_history
```

### 1. 圖像預處理

```python
def prepare_image(image_path, target_size=336):
    """預處理圖像以獲得最佳性能"""
    image = Image.open(image_path).convert('RGB')

    # 保持縱橫比縮放
    image.thumbnail((target_size, target_size), Image.LANCZOS)

    # 填充到正方形
    new_image = Image.new('RGB', (target_size, target_size), (255, 255, 255))
    new_image.paste(image, ((target_size - image.width) // 2,
                            (target_size - image.height) // 2))

    return new_image
```

### 3. 批量處理

```python
def batch_process_images(image_paths, model, batch_size=8):
    """批量處理圖像以提高效率"""
    results = []

    for i in range(0, len(image_paths), batch_size):
        batch = image_paths[i:i+batch_size]

        # 預處理
        images = [prepare_image(path) for path in batch]
        image_tensors = torch.stack([preprocess(img) for img in images])

        # 批量推理
        with torch.no_grad():
            outputs = model(image_tensors)

        results.extend(outputs)

    return results
```

### 4. 錯誤處理

```python
def safe_vision_query(image_path, prompt, model, max_retries=3):
    """帶重試的安全視覺查詢"""
    for attempt in range(max_retries):
        try:
            # 驗證圖像
            image = Image.open(image_path)
            if image.mode != 'RGB':
                image = image.convert('RGB')

            # 查詢
            response = model.generate(image=image, prompt=prompt)
            return response

        except Exception as e:
            print(f"嘗試 {attempt + 1} 失敗: {e}")
            if attempt == max_retries - 1:
                return f"處理失敗: {str(e)}"

    return None
```
