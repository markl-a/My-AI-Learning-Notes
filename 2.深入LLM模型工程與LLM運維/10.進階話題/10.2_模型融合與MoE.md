## 概述

模型融合和專家混合 (MoE) 是兩種提升 LLM 性能的重要技術：

- **模型融合**：組合多個已訓練模型的權重，建立性能更優的新模型
- **MoE**：在單個模型中使用多個"專家"子網絡，根據輸入動態選擇

### 為什麼重要？

| 技術 | 優勢 | 應用場景 |
|------|------|----------|
| **模型融合** | 無需訓練，快速組合能力 | 多任務模型、能力增強 |
| **MoE** | 高效利用參數，降低計算成本 | 大規模預訓練、多領域模型 |

## 模型融合 (Model Merging)

### 基本概念

模型融合通過組合多個模型的權重來建立新模型，無需額外訓練。

**簡單示例**：
```python
# 最簡單的融合：權重平均
merged_weight = 0.5 * model_A.weight + 0.5 * model_B.weight
```

### 融合方法

#### 1. 線性插值 (Linear Interpolation)

最基礎的融合方法：

$$
\theta_{\text{merged}} = \alpha \theta_A + (1-\alpha) \theta_B
$$

其中 $\alpha \in [0, 1]$ 是插值係數。

**優點**：簡單、快速
**缺點**：可能導致性能下降

#### 2. SLERP (Spherical Linear Interpolation)

球面線性插值，在高維空間中沿著球面路徑插值：

$$
\text{SLERP}(\theta_A, \theta_B, t) = \frac{\sin((1-t)\Omega)}{\sin(\Omega)}\theta_A + \frac{\sin(t\Omega)}{\sin(\Omega)}\theta_B
$$

其中 $\Omega = \arccos(\theta_A \cdot \theta_B / |\theta_A||\theta_B|)$

**優點**：保持向量長度，避免性能退化
**缺點**：計算稍複雜

#### 3. Task Arithmetic (任務向量)

**核心思想**：將特定能力視為向量，可以進行加減運算。

**任務向量定義**：

$$
\tau = \theta_{\text{finetuned}} - \theta_{\text{base}}
$$

**操作**：
- **添加能力**：$\theta_{\text{new}} = \theta_{\text{base}} + \alpha \tau$
- **移除能力**：$\theta_{\text{new}} = \theta_{\text{base}} - \alpha \tau$
- **組合能力**：$\theta_{\text{new}} = \theta_{\text{base}} + \alpha \tau_1 + \beta \tau_2$

**實際應用**：
```python
# 例如：組合數學能力和程式碼能力
base_model = load_model("llama-2-7b")
math_model = load_model("llama-2-7b-math")
code_model = load_model("llama-2-7b-code")

# 計算任務向量
math_vector = math_model.weights - base_model.weights
code_vector = code_model.weights - base_model.weights

# 組合
multi_skill_model = base_model.weights + 0.5 * math_vector + 0.5 * code_vector
```

#### 4. TIES-Merging

**問題**：直接平均可能導致參數衝突

**解決方案（TIES 三步驟）**：

1. **Trim**：修剪不重要的參數（閾值過濾）
2. **Elect Sign**：解決符號衝突（多數投票）
3. **Disjoint Merge**：合併非衝突參數

**演算法**：
```
For each parameter:
  1. 保留絕對值前 k% 的參數
  2. 統計正負符號，選擇多數符號
  3. 只平均符號一致的參數
```

#### 5. DARE (Drop And REscale)

**核心思想**：隨機丟棄部分微調參數，然後重新縮放

**演算法**：
```python
def dare_merge(base_weights, finetuned_weights, drop_rate=0.9, scaling=True):
    delta = finetuned_weights - base_weights

    # 隨機丟棄
    mask = torch.bernoulli(torch.ones_like(delta) * (1 - drop_rate))
    delta = delta * mask

    # 重新縮放
    if scaling:
        delta = delta / (1 - drop_rate)

    return base_weights + delta
```

**優勢**：
- 減少過擬合風險
- 提升融合穩定性
- 在多個基準測試中表現優異

### 融合策略選擇

| 場景 | 推薦方法 | 原因 |
|------|----------|------|
| 兩個相似模型 | Linear / SLERP | 簡單有效 |
| 多任務組合 | Task Arithmetic | 可控性強 |
| 多個微調模型 | TIES-Merging | 處理參數衝突 |
| 穩定性優先 | DARE | 減少過擬合 |

## Mixture of Experts (MoE)

### 基本架構

MoE 將傳統的前饋網絡替換為多個"專家"網絡，通過路由機制動態選擇。

**結構**：
```
輸入 → 路由器 (Router) → 選擇專家 → 專家處理 → 輸出
```

**詳細解釋請參考**：[Mixture of Experts 架構詳解](../1.LLM%20基礎與架構/Mixture_of_Experts_架構詳解.md)

### 核心組件

#### 1. 路由器 (Router/Gate)

決定哪些專家處理當前 token。

**Top-K 路由**：
```python
# 計算路由分數
router_logits = Router(input)  # (batch, num_experts)
router_probs = softmax(router_logits)

# 選擇 Top-K 專家
top_k_probs, top_k_indices = torch.topk(router_probs, k=2)
top_k_probs = top_k_probs / top_k_probs.sum(dim=-1, keepdim=True)

# 組合專家輸出
output = sum(top_k_probs[i] * Expert[top_k_indices[i]](input) for i in range(k))
```

#### 2. 專家網絡 (Experts)

多個並行的前饋網絡。

```python
class Expert(nn.Module):
    def __init__(self, d_model, d_ff):
        super().__init__()
        self.fc1 = nn.Linear(d_model, d_ff)
        self.fc2 = nn.Linear(d_ff, d_model)
        self.activation = nn.GELU()

    def forward(self, x):
        return self.fc2(self.activation(self.fc1(x)))
```

#### 3. 負載均衡

確保專家使用均勻，避免部分專家過載。

**負載均衡損失**：
```python
# 輔助損失，鼓勵均勻使用專家
load_balance_loss = num_experts * (f * P).sum()
```

其中：
- $f_i$：第 i 個專家的使用頻率
- $P_i$：分配給第 i 個專家的平均概率

### MoE 的優勢

1. **參數效率**：總參數多，但激活參數少
   - DeepSeek-V3: 671B 總參數，37B 激活

2. **計算效率**：FLOPs 與小模型相當
   - Mixtral-8x7B: 56B 參數，13B 激活

3. **專業化**：不同專家學習不同能力
   - 專家 1: 數學推理
   - 專家 2: 程式碼生成
   - 專家 3: 創意寫作

### 經典 MoE 模型

| 模型 | 總參數 | 激活參數 | 專家數 | Top-K |
|------|--------|----------|--------|-------|
| **Mixtral-8x7B** | 47B | 13B | 8 | 2 |
| **Mixtral-8x22B** | 141B | 39B | 8 | 2 |
| **DeepSeek-V3** | 671B | 37B | 256 | 8 |
| **Qwen-MoE** | 14.3B | 2.7B | 60 | 4 |

## 融合與 MoE 的結合

### Franken-MoE

**思路**：將多個微調模型的層作為 MoE 專家。

**構建流程**：
```
1. 準備多個微調模型（如不同任務的 Mistral-7B）
2. 提取每個模型的前饋層 (FFN)
3. 將這些 FFN 作為專家
4. 添加路由器網絡
5. 可選：微調路由器
```

**優勢**：
- 無需從頭訓練 MoE
- 組合現有模型的優勢
- 靈活擴展能力

**實現示例**（使用 mergekit）：
```yaml
base_model: mistralai/Mistral-7B-v0.1
gate_mode: random  # 或 hidden, cheap_embed
dtype: bfloat16

experts:
  - source_model: mistralai/Mistral-7B-Instruct-v0.2
    positive_prompts:
      - "chat"
      - "assistant"
      - "help"

  - source_model: WizardLM/WizardMath-7B-V1.1
    positive_prompts:
      - "math"
      - "calculate"
      - "solve"

  - source_model: codellama/CodeLlama-7b-hf
    positive_prompts:
      - "code"
      - "programming"
      - "python"

  - source_model: openchat/openchat-3.5-1210
    positive_prompts:
      - "reasoning"
      - "explain"
```

### 層級融合 (Layer-wise Merging)

**思路**：不同層使用不同的融合策略。

**示例**：
```python
def layer_wise_merge(models, layer_strategies):
    """
    models: 要融合的模型列表
    layer_strategies: 每層的融合策略
    """
    merged_model = copy.deepcopy(models[0])

    for layer_idx, strategy in enumerate(layer_strategies):
        if strategy == "average":
            # 簡單平均
            merged_model.layers[layer_idx] = average_layers(
                [m.layers[layer_idx] for m in models]
            )
        elif strategy == "task_vector":
            # 任務向量
            merged_model.layers[layer_idx] = task_vector_merge(
                models, layer_idx
            )
        elif strategy == "moe":
            # 轉換為 MoE
            merged_model.layers[layer_idx] = create_moe_layer(
                [m.layers[layer_idx] for m in models]
            )

    return merged_model
```

## Python 實作範例

### 1. 簡單的權重融合

```python
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer
import copy

def simple_merge(model_path_a, model_path_b, alpha=0.5):
    """
    簡單的線性插值融合

    Args:
        model_path_a: 模型 A 路徑
        model_path_b: 模型 B 路徑
        alpha: 插值係數 (0-1)
    """
    print(f"載入模型 A: {model_path_a}")
    model_a = AutoModelForCausalLM.from_pretrained(model_path_a)

    print(f"載入模型 B: {model_path_b}")
    model_b = AutoModelForCausalLM.from_pretrained(model_path_b)

    print(f"開始融合 (alpha={alpha})...")
    merged_model = copy.deepcopy(model_a)

    # 遍歷所有參數
    for name, param in merged_model.named_parameters():
        if name in dict(model_b.named_parameters()):
            param_a = param.data
            param_b = dict(model_b.named_parameters())[name].data

            # 線性插值
            param.data = alpha * param_a + (1 - alpha) * param_b

    print("融合完成！")
    return merged_model

# 使用示例
# merged = simple_merge("model_a", "model_b", alpha=0.5)
# merged.save_pretrained("merged_model")
```

### 2. SLERP 融合

```python
import torch
import math

def slerp(v0, v1, t):
    """
    球面線性插值

    Args:
        v0, v1: 輸入向量
        t: 插值參數 (0-1)
    """
    # 歸一化
    v0_norm = v0 / torch.norm(v0)
    v1_norm = v1 / torch.norm(v1)

    # 計算夾角
    dot = torch.sum(v0_norm * v1_norm)
    dot = torch.clamp(dot, -1.0, 1.0)
    omega = torch.acos(dot)

    # SLERP 公式
    so = torch.sin(omega)

    if so < 1e-6:
        # 向量幾乎平行，使用線性插值
        return (1.0 - t) * v0 + t * v1

    return (torch.sin((1.0 - t) * omega) / so) * v0 + (torch.sin(t * omega) / so) * v1

def slerp_merge(model_path_a, model_path_b, t=0.5):
    """使用 SLERP 融合模型"""
    model_a = AutoModelForCausalLM.from_pretrained(model_path_a)
    model_b = AutoModelForCausalLM.from_pretrained(model_path_b)

    merged_model = copy.deepcopy(model_a)

    for name, param in merged_model.named_parameters():
        if name in dict(model_b.named_parameters()):
            param_a = param.data.flatten()
            param_b = dict(model_b.named_parameters())[name].data.flatten()

            # 應用 SLERP
            merged_flat = slerp(param_a, param_b, t)

            # 恢復原始形狀
            param.data = merged_flat.reshape(param.shape)

    return merged_model

# 使用示例
# merged = slerp_merge("model_a", "model_b", t=0.5)
```

### 3. Task Arithmetic (任務向量)

```python
class TaskVector:
    """任務向量類"""

    def __init__(self, base_model_path, finetuned_model_path):
        """
        計算任務向量

        Args:
            base_model_path: 基礎模型路徑
            finetuned_model_path: 微調後模型路徑
        """
        self.base = AutoModelForCausalLM.from_pretrained(base_model_path)
        finetuned = AutoModelForCausalLM.from_pretrained(finetuned_model_path)

        # 計算差異向量
        self.vector = {}
        for name, param in self.base.named_parameters():
            if name in dict(finetuned.named_parameters()):
                ft_param = dict(finetuned.named_parameters())[name]
                self.vector[name] = ft_param.data - param.data

    def __add__(self, other):
        """支持任務向量相加"""
        result = TaskVector.__new__(TaskVector)
        result.base = self.base
        result.vector = {}

        for name in self.vector:
            if name in other.vector:
                result.vector[name] = self.vector[name] + other.vector[name]

        return result

    def __mul__(self, scalar):
        """支持標量乘法"""
        result = TaskVector.__new__(TaskVector)
        result.base = self.base
        result.vector = {name: vec * scalar for name, vec in self.vector.items()}
        return result

    def apply_to(self, model, scaling=1.0):
        """將任務向量應用到模型"""
        for name, param in model.named_parameters():
            if name in self.vector:
                param.data = param.data + scaling * self.vector[name]
        return model

# 使用示例
"""
# 計算任務向量
math_vector = TaskVector("llama-7b", "llama-7b-math")
code_vector = TaskVector("llama-7b", "llama-7b-code")

# 組合任務
combined = math_vector * 0.5 + code_vector * 0.5

# 應用到基礎模型
base_model = AutoModelForCausalLM.from_pretrained("llama-7b")
multi_skill_model = combined.apply_to(base_model)
"""
```

### 4. 簡化的 MoE 層實現

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class MoELayer(nn.Module):
    """簡化的 Mixture of Experts 層"""

    def __init__(self, d_model, d_ff, num_experts=8, top_k=2):
        super().__init__()
        self.num_experts = num_experts
        self.top_k = top_k

        # 路由器
        self.router = nn.Linear(d_model, num_experts)

        # 專家網絡
        self.experts = nn.ModuleList([
            nn.Sequential(
                nn.Linear(d_model, d_ff),
                nn.GELU(),
                nn.Linear(d_ff, d_model)
            )
            for _ in range(num_experts)
        ])

        # 負載均衡係數
        self.balance_loss_coef = 0.01

    def forward(self, x):
        """
        Args:
            x: (batch_size, seq_len, d_model)
        """
        batch_size, seq_len, d_model = x.shape
        x_flat = x.view(-1, d_model)  # (batch_size * seq_len, d_model)

        # 1. 路由決策
        router_logits = self.router(x_flat)  # (B*S, num_experts)
        router_probs = F.softmax(router_logits, dim=-1)

        # 2. 選擇 Top-K 專家
        top_k_probs, top_k_indices = torch.topk(router_probs, self.top_k, dim=-1)
        top_k_probs = top_k_probs / top_k_probs.sum(dim=-1, keepdim=True)  # 重新歸一化

        # 3. 計算專家輸出
        expert_outputs = torch.stack([expert(x_flat) for expert in self.experts])
        # expert_outputs: (num_experts, B*S, d_model)

        # 4. 加權組合
        output = torch.zeros_like(x_flat)
        for i in range(self.top_k):
            expert_idx = top_k_indices[:, i]  # (B*S,)
            expert_weight = top_k_probs[:, i].unsqueeze(-1)  # (B*S, 1)

            # 從專家輸出中選擇對應專家的輸出
            selected_output = expert_outputs[expert_idx, torch.arange(x_flat.size(0))]
            output += expert_weight * selected_output

        # 5. 計算負載均衡損失
        expert_usage = torch.zeros(self.num_experts, device=x.device)
        for i in range(self.num_experts):
            expert_usage[i] = (top_k_indices == i).float().mean()

        # 負載均衡損失：鼓勵均勻使用專家
        ideal_usage = 1.0 / self.num_experts
        balance_loss = ((expert_usage - ideal_usage) ** 2).sum()

        # 恢復形狀
        output = output.view(batch_size, seq_len, d_model)

        return output, balance_loss

# 測試 MoE 層
batch_size = 2
seq_len = 10
d_model = 512
d_ff = 2048

moe_layer = MoELayer(d_model, d_ff, num_experts=8, top_k=2)
x = torch.randn(batch_size, seq_len, d_model)

output, balance_loss = moe_layer(x)

print(f"輸入形狀: {x.shape}")
print(f"輸出形狀: {output.shape}")
print(f"負載均衡損失: {balance_loss.item():.4f}")

# 檢查專家使用情況
with torch.no_grad():
    router_logits = moe_layer.router(x.view(-1, d_model))
    router_probs = F.softmax(router_logits, dim=-1)
    expert_usage = router_probs.mean(dim=0)

    print("\n專家使用頻率:")
    for i, usage in enumerate(expert_usage):
        print(f"  專家 {i}: {usage.item()*100:.2f}%")
```

### 5. DARE 融合實現

```python
def dare_merge(base_model, finetuned_model, drop_rate=0.9, scaling=True):
    """
    DARE: Drop And REscale 融合

    Args:
        base_model: 基礎模型
        finetuned_model: 微調模型
        drop_rate: 丟棄率 (0-1)
        scaling: 是否重新縮放
    """
    merged_model = copy.deepcopy(base_model)

    for name, param in merged_model.named_parameters():
        if name in dict(finetuned_model.named_parameters()):
            base_param = param.data
            ft_param = dict(finetuned_model.named_parameters())[name].data

            # 計算差異
            delta = ft_param - base_param

            # 隨機丟棄
            mask = torch.bernoulli(torch.ones_like(delta) * (1 - drop_rate))
            delta = delta * mask

            # 重新縮放
            if scaling:
                delta = delta / (1 - drop_rate)

            # 應用
            param.data = base_param + delta

    return merged_model

# 使用示例
"""
base = AutoModelForCausalLM.from_pretrained("base_model")
finetuned = AutoModelForCausalLM.from_pretrained("finetuned_model")

merged = dare_merge(base, finetuned, drop_rate=0.9, scaling=True)
merged.save_pretrained("dare_merged_model")
"""
```

```python
def check_compatibility(model_a, model_b):
    params_a = dict(model_a.named_parameters())
    params_b = dict(model_b.named_parameters())

    # 檢查參數名稱
    if set(params_a.keys()) != set(params_b.keys()):
        print("警告：模型參數名稱不匹配")
        return False

    # 檢查參數形狀
    for name in params_a:
        if params_a[name].shape != params_b[name].shape:
            print(f"警告：{name} 形狀不匹配")
            return False

    print("模型兼容")
    return True
```

## 總結

### 關鍵要點

| 技術 | 何時使用 | 優勢 | 限制 |
|------|----------|------|------|
| **線性融合** | 快速實驗 | 簡單快速 | 可能性能下降 |
| **SLERP** | 兩模型融合 | 保持性能穩定 | 只適用於兩個模型 |
| **Task Arithmetic** | 能力組合 | 可控、靈活 | 需要相同基礎模型 |
| **TIES/DARE** | 多模型融合 | 處理衝突、穩定 | 稍複雜 |
| **MoE** | 大規模預訓練 | 參數效率高 | 訓練複雜 |
| **Franken-MoE** | 組合現有模型 | 無需訓練 | 需要微調路由 |
