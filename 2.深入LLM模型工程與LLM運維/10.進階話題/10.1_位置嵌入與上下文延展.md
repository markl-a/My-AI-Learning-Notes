## 位置編碼的重要性

### 為什麼需要位置編碼？

Transformer 的自注意力機制本身是**置換不變**的（permutation-invariant），也就是說，如果打亂輸入序列的順序，輸出結果不會改變。但對於語言理解來說，詞序是至關重要的。

**例如**：
- "狗追貓" 和 "貓追狗" 語義完全不同
- 沒有位置資訊，模型無法區分這兩個句子

位置編碼的作用就是為每個 token 添加位置資訊，讓模型能夠理解序列的順序。

### 位置編碼的演進

```
原始 Transformer (2017)
└─ 絕對位置編碼（Sinusoidal）

Transformer-XL (2019)
└─ 相對位置編碼

RoFormer (2021)
└─ RoPE（旋轉位置編碼）

BLOOM (2022)
└─ ALiBi（線性偏置注意力）

LongRoPE, YaRN (2023-2024)
└─ 上下文長度延展
```

## RoPE (Rotary Position Embedding)

### 核心思想

RoPE 通過**旋轉矩陣**將位置資訊編碼到 Query 和 Key 向量中，使得注意力分數天然地包含相對位置資訊。

### 數學原理

對於位置 $m$ 的 token，其向量 $\mathbf{q}$ 經過 RoPE 編碼後變為：

$$
\text{RoPE}(\mathbf{q}, m) = \mathbf{R}_m \mathbf{q}
$$

其中 $\mathbf{R}_m$ 是旋轉矩陣：

$$
\mathbf{R}_m = \begin{bmatrix}
\cos(m\theta_1) & -\sin(m\theta_1) & 0 & 0 & \cdots \\
\sin(m\theta_1) & \cos(m\theta_1) & 0 & 0 & \cdots \\
0 & 0 & \cos(m\theta_2) & -\sin(m\theta_2) & \cdots \\
0 & 0 & \sin(m\theta_2) & \cos(m\theta_2) & \cdots \\
\vdots & \vdots & \vdots & \vdots & \ddots
\end{bmatrix}
$$

頻率 $\theta_i = 10000^{-2i/d}$，其中 $d$ 是向量維度。

### 相對位置特性

兩個位置 $m$ 和 $n$ 的 Query-Key 內積：

$$
(\mathbf{R}_m \mathbf{q})^T (\mathbf{R}_n \mathbf{k}) = \mathbf{q}^T \mathbf{R}_{n-m} \mathbf{k}
$$

**關鍵特性**：內積只依賴於相對位置 $(n-m)$，而非絕對位置！

### 優勢

1. **相對位置編碼**：天然捕捉相對位置關系
2. **線性復雜度**：計算效率高
3. **良好的外推性**：可以處理比訓練時更長的序列
4. **無需額外參數**：不增加模型參數量

### 使用 RoPE 的模型

- **LLaMA 系列**：LLaMA 1/2/3
- **GPT-NeoX**：EleutherAI 的開源模型
- **PaLM**：Google 的大型語言模型
- **Qwen**：阿里雲的千問系列

## ALiBi (Attention with Linear Biases)

### 核心思想

ALiBi 不在嵌入層添加位置資訊，而是在**注意力分數**上添加一個與距離成正比的負偏置。

### 數學原理

標準注意力分數：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V
$$

ALiBi 修改為：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}} + \mathbf{m} \cdot \text{bias}\right) V
$$

其中偏置矩陣：

$$
\text{bias}_{ij} = -(i - j) \quad \text{當 } i \geq j
$$

$\mathbf{m}$ 是每個頭的斜率（slope），對於 8 個頭：

$$
\mathbf{m} = \left[\frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \frac{1}{16}, \frac{1}{32}, \frac{1}{64}, \frac{1}{128}, \frac{1}{256}\right]
$$

### 視覺化示例

對於序列長度為 5 的情況，偏置矩陣（head 1，m=1）：

```
     0    1    2    3    4
0 [  0   -∞   -∞   -∞   -∞ ]
1 [ -1    0   -∞   -∞   -∞ ]
2 [ -2   -1    0   -∞   -∞ ]
3 [ -3   -2   -1    0   -∞ ]
4 [ -4   -3   -2   -1    0 ]
```

### 優勢

1. **訓練效率高**：無需位置嵌入，減少計算
2. **強外推能力**：可以直接處理任意長度序列
3. **簡單實現**：只需修改注意力計算
4. **性能穩定**：在多種任務上表現良好

### 使用 ALiBi 的模型

- **BLOOM**：BigScience 的 176B 參數模型
- **MPT**：MosaicML 的預訓練 Transformer
- **Falcon**：TII 的開源模型

## YaRN (Yet another RoPE extensioN method)

### 背景問題

RoPE 雖然有一定的外推能力，但當上下文長度遠超訓練長度時，性能會顯著下降。

**問題**：
- 訓練長度：4K tokens
- 推理長度：32K tokens
- 結果：困惑度（perplexity）急劇上升

### YaRN 的解決方案

YaRN 通過**非均勻插值**和**注意力溫度調整**來延展上下文長度。

#### 1. 非均勻插值（Non-uniform Interpolation）

將旋轉頻率 $\theta_i$ 調整為：

$$
\theta_i' = \theta_i / s_i
$$

其中縮放因子 $s_i$ 根據頻率範圍動態調整：

$$
s_i = \begin{cases}
1 & \text{高頻部分（保持不變）} \\
\text{插值} & \text{中頻部分（平滑過渡）} \\
s & \text{低頻部分（縮放）}
\end{cases}
$$

**直覺**：
- **高頻**：捕捉局部資訊，不需要調整
- **低頻**：捕捉長距離依賴，需要縮放以適應更長上下文

#### 2. 注意力溫度調整

添加一個溫度因子 $t$：

$$
\text{Attention} = \text{softmax}\left(\frac{QK^T}{t\sqrt{d_k}}\right) V
$$

其中 $t = \sqrt{\ln(s) / \ln(s_0)}$，$s$ 是延展倍數。

### YaRN 的效果

- **LLaMA-7B**：從 4K 延展到 128K tokens
- **性能損失小**：困惑度僅略有上升
- **微調高效**：只需在長文字上微調少量步驟

## 其他上下文延展技術

### 1. Position Interpolation (PI)

**思路**：直接將位置索引線性縮放

$$
\text{position}_{\text{new}} = \text{position}_{\text{old}} \times \frac{L_{\text{train}}}{L_{\text{inference}}}
$$

**優點**：簡單直接
**缺點**：可能損失高頻資訊

### 2. NTK-aware Scaled RoPE

**思路**：調整 RoPE 的基礎頻率

$$
\theta_i = (10000 \times s^{d/(d-2)})^{-2i/d}
$$

其中 $s$ 是延展倍數。

### 3. LongRoPE

**核心**：
- **非均勻重新縮放**：類似 YaRN
- **進化搜索**：自動搜索最優縮放參數
- **8K → 2048K**：LLaMA-3-8B 達到 200 萬 token

### 4. Positional Skip-wise (PoSE)

**思路**：訓練時隨機跳過部分位置

**例如**：
- 原始位置：[0, 1, 2, 3, 4, 5, 6, 7]
- 跳過後：[0, 2, 4, 6, 8, 10, 12, 14]

**效果**：模型學習處理稀疏位置，提升外推能力

## 長上下文的挑戰與解決方案

### 主要挑戰

#### 1. 計算複雜度

注意力機制的時間複雜度：$O(n^2)$

**問題**：
- 4K tokens：16M 計算
- 128K tokens：16B 計算（1000倍）

**解決方案**：
- **Flash Attention**：優化內存訪問，2-4x 加速
- **Sparse Attention**：只計算部分注意力（如 Longformer）
- **Linear Attention**：將複雜度降至 $O(n)$（如 RWKV）

#### 2. 內存消耗

**KV Cache**：存儲所有 token 的 Key 和 Value

內存需求：

$$
\text{Memory} = 2 \times n_{\text{layers}} \times n_{\text{tokens}} \times d_{\text{model}} \times \text{precision}
$$

**例如**（LLaMA-7B，128K tokens）：
- Layers: 32
- d_model: 4096
- Precision: FP16 (2 bytes)
- Memory: 2 × 32 × 128K × 4096 × 2 ≈ 64 GB

**解決方案**：
- **Multi-Query Attention (MQA)**：共享 KV，減少內存
- **Grouped-Query Attention (GQA)**：部分共享
- **PagedAttention**：分頁管理 KV Cache（vLLM）

#### 3. 訓練困難

**問題**：
- 長序列資料稀缺
- 訓練成本高
- 梯度傳播困難

**解決方案**：
- **漸進式訓練**：從短到長逐步增加長度
- **合成資料**：生成長文字訓練資料
- **部分微調**：只微調部分層或參數

#### 4. 評估挑戰

**問題**：
- 缺乏標準的長上下文評估基準
- 困惑度不能完全反映實際能力

**解決方案**：
- **Needle in a Haystack**：測試資訊檢索能力
- **LongBench**：多任務長上下文基準
- **實際應用測試**：文檔問答、程式碼理解

## Python 實作範例

### 1. RoPE 實現

```python
import torch
import torch.nn as nn
import math

class RotaryPositionalEmbedding(nn.Module):
    """RoPE 旋轉位置編碼實現"""

    def __init__(self, dim, max_seq_len=2048, base=10000):
        super().__init__()
        self.dim = dim
        self.max_seq_len = max_seq_len
        self.base = base

        # 計算旋轉頻率
        inv_freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))
        self.register_buffer('inv_freq', inv_freq)

        # 預計算旋轉矩陣
        self._setup_cos_sin_cache(max_seq_len)

    def _setup_cos_sin_cache(self, seq_len):
        """預計算 cos 和 sin 值"""
        t = torch.arange(seq_len, dtype=self.inv_freq.dtype)
        freqs = torch.outer(t, self.inv_freq)  # (seq_len, dim/2)
        emb = torch.cat([freqs, freqs], dim=-1)  # (seq_len, dim)

        self.register_buffer('cos_cached', emb.cos()[None, :, None, :])
        self.register_buffer('sin_cached', emb.sin()[None, :, None, :])

    def rotate_half(self, x):
        """旋轉操作：將向量的前半部分和後半部分交換並取負"""
        x1, x2 = x.chunk(2, dim=-1)
        return torch.cat([-x2, x1], dim=-1)

    def forward(self, q, k, seq_len=None):
        """
        Args:
            q: Query (batch, seq_len, num_heads, head_dim)
            k: Key (batch, seq_len, num_heads, head_dim)
        """
        if seq_len is None:
            seq_len = q.shape[1]

        # 如果序列長度超過快取，重新計算
        if seq_len > self.max_seq_len:
            self._setup_cos_sin_cache(seq_len)

        cos = self.cos_cached[:, :seq_len, :, :]
        sin = self.sin_cached[:, :seq_len, :, :]

        # 應用旋轉
        q_embed = q * cos + self.rotate_half(q) * sin
        k_embed = k * cos + self.rotate_half(k) * sin

        return q_embed, k_embed

# 測試 RoPE
batch_size = 2
seq_len = 10
num_heads = 8
head_dim = 64

q = torch.randn(batch_size, seq_len, num_heads, head_dim)
k = torch.randn(batch_size, seq_len, num_heads, head_dim)

rope = RotaryPositionalEmbedding(dim=head_dim)
q_rotated, k_rotated = rope(q, k)

print(f"原始 Q 形狀: {q.shape}")
print(f"旋轉後 Q 形狀: {q_rotated.shape}")

# 驗證相對位置特性
pos_0 = q_rotated[:, 0, :, :]  # 位置 0
pos_5 = q_rotated[:, 5, :, :]  # 位置 5
pos_1 = q_rotated[:, 1, :, :]  # 位置 1
pos_6 = q_rotated[:, 6, :, :]  # 位置 6

# 計算內積（應該相似，因為相對位置相同）
sim_0_5 = torch.cosine_similarity(pos_0[0, 0], pos_5[0, 0], dim=0)
sim_1_6 = torch.cosine_similarity(pos_1[0, 0], pos_6[0, 0], dim=0)
print(f"\n位置 0-5 相似度: {sim_0_5:.4f}")
print(f"位置 1-6 相似度: {sim_1_6:.4f}")
print("（相對位置相同時，內積應該相近）")
```

### 2. ALiBi 實現

```python
class ALiBiAttention(nn.Module):
    """ALiBi 注意力機制實現"""

    def __init__(self, num_heads, max_seq_len=2048):
        super().__init__()
        self.num_heads = num_heads
        self.max_seq_len = max_seq_len

        # 計算每個頭的斜率
        slopes = self._get_slopes(num_heads)
        self.register_buffer('slopes', slopes)

        # 預計算偏置矩陣
        alibi = self._build_alibi_bias(max_seq_len, slopes)
        self.register_buffer('alibi', alibi)

    def _get_slopes(self, num_heads):
        """計算每個頭的斜率"""
        # 使用幾何級數: 2^(-8/n), 2^(-16/n), ...
        def get_slopes_power_of_2(n):
            start = 2 ** (-2 ** -(math.log2(n) - 3))
            ratio = start
            return [start * (ratio ** i) for i in range(n)]

        # 如果頭數不是 2 的冪，需要特殊處理
        if math.log2(num_heads).is_integer():
            return torch.tensor(get_slopes_power_of_2(num_heads))
        else:
            closest_power_of_2 = 2 ** math.floor(math.log2(num_heads))
            slopes_1 = get_slopes_power_of_2(closest_power_of_2)
            slopes_2 = get_slopes_power_of_2(2 * closest_power_of_2)[::2]
            slopes = slopes_1 + slopes_2[:num_heads - closest_power_of_2]
            return torch.tensor(slopes)

    def _build_alibi_bias(self, max_seq_len, slopes):
        """構建 ALiBi 偏置矩陣"""
        # 建立距離矩陣
        position = torch.arange(max_seq_len).unsqueeze(0)
        distance = position - position.T

        # 只保留下三角部分（因果掩碼）
        distance = distance.unsqueeze(0).expand(self.num_heads, -1, -1)

        # 應用斜率
        alibi = distance * slopes.view(-1, 1, 1)

        # 掩蓋未來位置
        mask = torch.triu(torch.ones(max_seq_len, max_seq_len), diagonal=1).bool()
        alibi = alibi.masked_fill(mask.unsqueeze(0), float('-inf'))

        return alibi  # (num_heads, max_seq_len, max_seq_len)

    def forward(self, query, key, value):
        """
        Args:
            query, key, value: (batch, num_heads, seq_len, head_dim)
        """
        batch_size, num_heads, seq_len, head_dim = query.shape

        # 標準注意力分數
        scores = torch.matmul(query, key.transpose(-2, -1)) / math.sqrt(head_dim)

        # 添加 ALiBi 偏置
        alibi_bias = self.alibi[:, :seq_len, :seq_len]  # 截取到當前序列長度
        scores = scores + alibi_bias.unsqueeze(0)  # 廣播到 batch

        # Softmax
        attn_weights = torch.softmax(scores, dim=-1)

        # 計算輸出
        output = torch.matmul(attn_weights, value)

        return output, attn_weights

# 測試 ALiBi
batch_size = 2
num_heads = 8
seq_len = 16
head_dim = 64

query = torch.randn(batch_size, num_heads, seq_len, head_dim)
key = torch.randn(batch_size, num_heads, seq_len, head_dim)
value = torch.randn(batch_size, num_heads, seq_len, head_dim)

alibi_attn = ALiBiAttention(num_heads=num_heads)
output, weights = alibi_attn(query, key, value)

print(f"輸出形狀: {output.shape}")
print(f"注意力權重形狀: {weights.shape}")

# 視覺化偏置矩陣
import matplotlib.pyplot as plt

plt.figure(figsize=(12, 4))
for i in range(min(3, num_heads)):
    plt.subplot(1, 3, i+1)
    bias = alibi_attn.alibi[i, :seq_len, :seq_len].numpy()
    # 將 -inf 替換為 nan 以便視覺化
    bias[bias == float('-inf')] = float('nan')
    plt.imshow(bias, cmap='RdBu_r', aspect='auto')
    plt.title(f'Head {i+1} (slope={alibi_attn.slopes[i]:.4f})')
    plt.xlabel('Key Position')
    plt.ylabel('Query Position')
    plt.colorbar()

plt.tight_layout()
plt.savefig('alibi_bias.png', dpi=100, bbox_inches='tight')
plt.close()
print("\nALiBi 偏置矩陣已保存到 alibi_bias.png")
```

### 3. YaRN 實現（簡化版）

```python
class YaRNRotaryEmbedding(nn.Module):
    """YaRN: 改進的 RoPE 上下文延展"""

    def __init__(self, dim, max_seq_len=2048, base=10000,
                 original_max_seq_len=2048, scale=1.0):
        super().__init__()
        self.dim = dim
        self.max_seq_len = max_seq_len
        self.base = base
        self.scale = scale  # 延展倍數

        # YaRN 的非均勻插值參數
        self.alpha = 1.0  # 低頻縮放因子
        self.beta = 32.0   # 高頻閾值

        # 計算調整後的頻率
        inv_freq = self._compute_yarn_freq(dim, base, scale)
        self.register_buffer('inv_freq', inv_freq)

        # 計算注意力溫度
        self.attn_factor = self._compute_attn_factor(scale)

        self._setup_cos_sin_cache(max_seq_len)

    def _compute_yarn_freq(self, dim, base, scale):
        """計算 YaRN 調整後的頻率"""
        freq = 1.0 / (base ** (torch.arange(0, dim, 2).float() / dim))

        if scale <= 1.0:
            return freq

        # 非均勻插值
        wavelength = 2 * math.pi / freq

        # 計算每個頻率的縮放因子
        scale_factors = torch.ones_like(freq)
        for i, wl in enumerate(wavelength):
            if wl < self.beta:
                # 高頻部分：不縮放
                scale_factors[i] = 1.0
            elif wl > self.beta * scale:
                # 低頻部分：完全縮放
                scale_factors[i] = scale
            else:
                # 中頻部分：平滑插值
                gamma = (wl - self.beta) / (self.beta * scale - self.beta)
                scale_factors[i] = 1.0 + (scale - 1.0) * gamma

        return freq / scale_factors

    def _compute_attn_factor(self, scale):
        """計算注意力溫度因子"""
        if scale <= 1.0:
            return 1.0
        return math.sqrt(1 + math.log(scale) / math.log(self.base))

    def _setup_cos_sin_cache(self, seq_len):
        t = torch.arange(seq_len, dtype=self.inv_freq.dtype)
        freqs = torch.outer(t, self.inv_freq)
        emb = torch.cat([freqs, freqs], dim=-1)

        self.register_buffer('cos_cached', emb.cos()[None, :, None, :])
        self.register_buffer('sin_cached', emb.sin()[None, :, None, :])

    def rotate_half(self, x):
        x1, x2 = x.chunk(2, dim=-1)
        return torch.cat([-x2, x1], dim=-1)

    def forward(self, q, k, seq_len=None):
        if seq_len is None:
            seq_len = q.shape[1]

        cos = self.cos_cached[:, :seq_len, :, :]
        sin = self.sin_cached[:, :seq_len, :, :]

        q_embed = q * cos + self.rotate_half(q) * sin
        k_embed = k * cos + self.rotate_half(k) * sin

        # 應用注意力溫度調整
        q_embed = q_embed / self.attn_factor

        return q_embed, k_embed

# 2. YaRN RoPE (4x 延展)
```

```python
import matplotlib.pyplot as plt
import numpy as np

def visualize_position_encodings():
    """視覺化不同位置編碼方法"""

    seq_len = 128
    dim = 64

    # 1. 原始 Sinusoidal
    def sinusoidal_encoding(seq_len, dim):
        position = np.arange(seq_len)[:, np.newaxis]
        div_term = np.exp(np.arange(0, dim, 2) * -(np.log(10000.0) / dim))

        pe = np.zeros((seq_len, dim))
        pe[:, 0::2] = np.sin(position * div_term)
        pe[:, 1::2] = np.cos(position * div_term)
        return pe

    # 2. RoPE (簡化視覺化)
    def rope_encoding(seq_len, dim):
        inv_freq = 1.0 / (10000 ** (np.arange(0, dim, 2) / dim))
        t = np.arange(seq_len)
        freqs = np.outer(t, inv_freq)
        emb = np.concatenate([freqs, freqs], axis=-1)
        return np.cos(emb)  # 簡化：只顯示 cos 部分

    # 生成編碼
    sin_enc = sinusoidal_encoding(seq_len, dim)
    rope_enc = rope_encoding(seq_len, dim)

    # 視覺化
    fig, axes = plt.subplots(2, 2, figsize=(14, 10))

    # Sinusoidal 熱圖
    im1 = axes[0, 0].imshow(sin_enc.T, aspect='auto', cmap='RdBu')
```

```python
def benchmark_context_length():
    """測試不同上下文長度的性能"""

    import time

    print("="*60)

    head_dim = 64
    num_heads = 8

    context_lengths = [1024, 2048, 4096, 8192, 16384]

    results = {
        'Standard RoPE': [],
        'YaRN RoPE': [],
        'ALiBi': []
    }

    for seq_len in context_lengths:
        print(f"\n測試序列長度: {seq_len}")

        q = torch.randn(batch_size, seq_len, num_heads, head_dim)
        k = torch.randn(batch_size, seq_len, num_heads, head_dim)

        # 1. Standard RoPE
        rope = RotaryPositionalEmbedding(dim=head_dim, max_seq_len=seq_len)
        start = time.time()
        _ = rope(q, k)
        elapsed = time.time() - start
        results['Standard RoPE'].append(elapsed * 1000)  # ms
        print(f"  Standard RoPE: {elapsed*1000:.2f} ms")

        # 2. YaRN RoPE
        yarn = YaRNRotaryEmbedding(dim=head_dim, max_seq_len=seq_len, scale=2.0)
        start = time.time()
        _ = yarn(q, k)
        elapsed = time.time() - start
        results['YaRN RoPE'].append(elapsed * 1000)
        print(f"  YaRN RoPE: {elapsed*1000:.2f} ms")

        # 3. ALiBi (只需要計算偏置，更快)
        q_heads = q.transpose(1, 2)  # (batch, heads, seq, dim)
        k_heads = k.transpose(1, 2)

        alibi_attn = ALiBiAttention(num_heads=num_heads, max_seq_len=seq_len)
        start = time.time()
        _ = alibi_attn(q_heads, k_heads, v_heads)
        elapsed = time.time() - start
        results['ALiBi'].append(elapsed * 1000)
        print(f"  ALiBi: {elapsed*1000:.2f} ms")

    # 繪製結果
```

## 實用建議

### 選擇位置編碼方案

#### 1. 標準應用場景
**推薦：RoPE**
- 已在 LLaMA、GPT-NeoX 等模型中驗證
- 性能穩定，外推能力適中
- 實現簡單，計算高效

#### 2. 超長上下文場景
**推薦：YaRN 或 LongRoPE**
- 需要處理遠超訓練長度的序列
- 適合文檔分析、長對話
- 微調成本相對較低

#### 3. 訓練效率優先
**推薦：ALiBi**
- 無需位置嵌入，減少參數
- 訓練速度快
- 可直接外推到任意長度

### 上下文延展策略

#### 漸進式延展

#### 內存優化
```python
# 使用 GQA 減少 KV Cache
# LLaMA-3 使用 8 組，每組共享 KV

# 估算內存需求
def estimate_kv_cache_memory(
    num_layers,
    num_heads,
    head_dim,
    seq_len,
    batch_size,
    num_kv_heads=None  # GQA
):
    if num_kv_heads is None:
        num_kv_heads = num_heads  # MHA

    # 每個 token 的 KV：2 (K,V) × num_layers × num_kv_heads × head_dim
    bytes_per_token = 2 * num_layers * num_kv_heads * head_dim * 2  # FP16
    total_bytes = bytes_per_token * seq_len * batch_size

    return total_bytes / (1024**3)  # GB

# LLaMA-7B, 128K context
memory_mha = estimate_kv_cache_memory(32, 32, 128, 128000, 1)
memory_gqa = estimate_kv_cache_memory(32, 32, 128, 128000, 1, num_kv_heads=8)

print(f"MHA 內存: {memory_mha:.2f} GB")
print(f"GQA 內存: {memory_gqa:.2f} GB")
print(f"節省: {(1 - memory_gqa/memory_mha)*100:.1f}%")
```

#### 推論優化
- **PagedAttention**：分頁管理 KV Cache（vLLM）
- **Flash Attention**：優化內存訪問模式
- **Sparse Attention**：只計算重要的注意力
