# 2025年 LLM 訓練與優化技術全景

## 概述

2025年，LLM 訓練與優化技術取得了重大突破。從參數高效微調（PEFT）到強化學習對齊（Alignment），再到推理優化技術，整個技術棧日趨成熟。本文檔全面介紹最新的訓練、微調和優化技術。

---

## 一、參數高效微調（PEFT）技術

### 1. LoRA（Low-Rank Adaptation）

**核心概念：**
- 在預訓練 LLM 上添加少量低秩適配器層
- 僅訓練適配器參數，凍結主模型
- 大幅減少可訓練參數和內存需求

**數學原理：**
```
W_new = W + ΔW
ΔW = AB^T  (其中 A ∈ R^(d×r), B ∈ R^(r×k), r << min(d,k))
```

**優勢：**
- 訓練參數減少 99%+
- 內存需求降低 3-5倍
- 訓練速度提升 2-3倍
- 易於部署多個適配器

**實踐建議（Sebastian Raschka，2025）：**
- **Rank (r)**：建議從 8 開始，複雜任務可嘗試 16-32
- **Alpha**：通常設為 r 的 2 倍（如 r=8, alpha=16）
- **Target Modules**：
  - 最小配置：`q_proj`, `v_proj`
  - 推薦配置：`q_proj`, `k_proj`, `v_proj`, `o_proj`
  - 完整配置：所有注意力層 + MLP 層

**實現示例：**
```python
from peft import LoraConfig, get_peft_model
from transformers import AutoModelForCausalLM

# 加載基礎模型
base_model = AutoModelForCausalLM.from_pretrained("meta-llama/Llama-3.1-8B")

# LoRA 配置
lora_config = LoraConfig(
    r=16,  # Rank
    lora_alpha=32,  # Alpha
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

# 應用 LoRA
model = get_peft_model(base_model, lora_config)

# 查看可訓練參數
model.print_trainable_parameters()
# Output: trainable params: 8,388,608 || all params: 8,030,261,248 || trainable%: 0.104%
```

### 2. QLoRA（Quantized LoRA）

**突破性創新：**
- 將預訓練模型量化為 4-bit
- 在量化模型上訓練 LoRA 適配器
- 保持接近全精度的性能

**性能數據（2025）：**
- **內存節省**：33%（相比 LoRA）
- **訓練時間**：增加 39%（速度換內存的權衡）
- **性能損失**：< 1%（幾乎無損）

**2025年推薦配置（Llama 3.1 8B）：**
```python
from transformers import BitsAndBytesConfig
from peft import LoraConfig, prepare_model_for_kbit_training, get_peft_model

# 4-bit 量化配置
bnb_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_use_double_quant=True,  # 雙重量化
    bnb_4bit_quant_type="nf4",  # 正規化浮點 4-bit
    bnb_4bit_compute_dtype=torch.bfloat16  # 計算精度
)

# 加載量化模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.1-8B",
    quantization_config=bnb_config,
    device_map="auto"
)

# 準備模型
model = prepare_model_for_kbit_training(model)

# 應用 LoRA
lora_config = LoraConfig(
    r=16,
    lora_alpha=32,
    target_modules=["q_proj", "k_proj", "v_proj", "o_proj"],
    lora_dropout=0.05,
    bias="none",
    task_type="CAUSAL_LM"
)

model = get_peft_model(model, lora_config)
```

**實際案例：**
- 單個 GPU（24GB）即可微調 Llama 3.1 8B
- 適合研究者和小團隊
- 成本大幅降低

### 3. Spectrum 與其他 PEFT 技術

**2025年新興技術：**
- **Spectrum**：結合 QLoRA 的新方法

## 二、對齊技術（Alignment）

### 1. RLHF（Reinforcement Learning with Human Feedback）

**經典三階段流程：**

**階段 1：監督微調（SFT）**
```python
from transformers import Trainer, TrainingArguments

training_args = TrainingArguments(
    output_dir="./sft_model",
    num_train_epochs=3,
    per_device_train_batch_size=4,
    learning_rate=2e-5,
    fp16=True
)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=instruction_dataset
)

trainer.train()
```

**階段 2：獎勵模型訓練**
```python
# 使用人類偏好數據訓練獎勵模型
reward_model = train_reward_model(
    base_model=base_model,
    preference_data=preference_dataset
)
```

**階段 3：PPO 優化**
```python
from trl import PPOTrainer, PPOConfig

ppo_config = PPOConfig(
    learning_rate=1.41e-5,
    batch_size=64,
    mini_batch_size=8,
    ppo_epochs=4
)

ppo_trainer = PPOTrainer(
    config=ppo_config,
    model=sft_model,
    ref_model=ref_model,
    reward_model=reward_model,
    dataset=prompt_dataset
)

ppo_trainer.train()
```

**挑戰：**
- 複雜的三階段流程
- 需要大量計算資源
- 訓練不穩定（PPO 難調）

### 2. DPO（Direct Preference Optimization）

**2025年首選對齊方法：**
- 簡化 RLHF，去除獎勵模型和 PPO
- 將對齊問題視為分類任務
- 更穩定、更高效、計算成本更低

**核心思想：**
```
將 RLHF 的獎勵重新參數化為策略本身的隱式獎勵
通過監督學習直接優化 RLHF 目標
```

**優勢對比：**
| 特性 | RLHF | DPO |
|-----|------|-----|
| 階段數 | 3 | 2 |
| 穩定性 | 中低 | 高 |
| 計算成本 | 高 | 低 |
| 實現複雜度 | 高 | 低 |
| 性能 | 優秀 | 優秀 |

**實現示例：**
```python
from trl import DPOTrainer, DPOConfig
from transformers import AutoModelForCausalLM, AutoTokenizer

# 加載 SFT 模型
model = AutoModelForCausalLM.from_pretrained("path/to/sft_model")
ref_model = AutoModelForCausalLM.from_pretrained("path/to/sft_model")
tokenizer = AutoTokenizer.from_pretrained("path/to/sft_model")

# DPO 配置
dpo_config = DPOConfig(
    beta=0.1,  # KL 散度懲罰係數
    learning_rate=5e-7,
    num_train_epochs=3,
    per_device_train_batch_size=4,
    gradient_accumulation_steps=4
)

# DPO 訓練器
dpo_trainer = DPOTrainer(
    model=model,
    ref_model=ref_model,
    args=dpo_config,
    train_dataset=preference_dataset,
    tokenizer=tokenizer
)

dpo_trainer.train()
```

**DPO 與 LoRA 結合：**
```python
# DPO Full Training vs. DPO with LoRA
# LoRA 可達到 Full Training 90-95% 的性能
# 但內存需求降低 70%+

from peft import LoraConfig, get_peft_model

# 應用 LoRA
lora_config = LoraConfig(r=16, lora_alpha=32, ...)
model = get_peft_model(model, lora_config)

# DPO 訓練（與上述相同）
dpo_trainer = DPOTrainer(...)
```

**2025年最佳實踐（Phil Schmid）：**
- 使用 DPO 而非 RLHF（更簡單、更穩定）
- 結合 LoRA 降低內存需求
- 使用合成數據（Synthetic Data）擴充偏好數據
- Beta 參數從 0.1 開始調優

### 3. 其他對齊技術

**ORPO（Odds Ratio Preference Optimization）：**
- 2025年新興技術
- 單階段對齊（無需 SFT）
- 更高效的對齊方法

**RLAIF（RL from AI Feedback）：**
- 使用 AI 反饋替代人類反饋
- 降低標註成本
- 可擴展性更強

**Constitutional AI：**
- Anthropic 提出
- 基於原則的對齊
- 提升模型安全性

## 三、推理優化技術

### 1. 量化（Quantization）

**2025年趨勢：超低比特量化**

**量化方法對比：**
| 方法 | 比特數 | 精度損失 | 模型大小 | 速度提升 |
|-----|-------|---------|---------|---------|
| FP32 | 32-bit | 0% (基準) | 100% | 1x |
| FP16 | 16-bit | <1% | 50% | 1.5x |
| INT8 | 8-bit | <2% | 25% | 2-3x |
| INT4 | 4-bit | 2-5% | 12.5% | 3-4x |
| INT2 | 2-bit | 5-10% | 6.25% | 4-5x |
| INT1 | 1-bit | 10-15% | 3.13% | 5-6x |

**2025年主流方法：**
- **GPTQ**：後訓練量化，適合推理
- **AWQ**（Activation-aware Weight Quantization）：感知激活的權化量化
- **GGUF**（llama.cpp）：跨平台量化格式
- **bitsandbytes**：QLoRA 使用的量化庫

**實現示例（4-bit 量化推理）：**
```python
from transformers import AutoModelForCausalLM, BitsAndBytesConfig

# 4-bit 量化配置
quantization_config = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_compute_dtype=torch.bfloat16,
    bnb_4bit_use_double_quant=True,
    bnb_4bit_quant_type="nf4"
)

# 加載量化模型
model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.1-8B",
    quantization_config=quantization_config,
    device_map="auto"
)

# 推理
output = model.generate(**inputs, max_new_tokens=100)
```

### 2. 剪枝（Pruning）

**2025年技術進展：**

**動態結構化剪枝：**
- 實時輸入特徵感知
- 動態關閉冗餘神經元
- 保持準確率，顯著提升速度

**DeepSeek-R1 案例：**
- 使用"注意力門控"（Attention Gating）機制
- 推理時僅保持 20% 的權重活躍
- 推理速度提升 **3倍**
- 準確率損失 < 0.5%

**實現示例：**
```python
from transformers import AutoModelForCausalLM
import torch.nn.utils.prune as prune

model = AutoModelForCausalLM.from_pretrained("model_name")

# 結構化剪枝
for name, module in model.named_modules():
    if isinstance(module, torch.nn.Linear):
        prune.l1_unstructured(module, name='weight', amount=0.3)
        prune.remove(module, 'weight')  # 永久移除
```

**剪枝類型：**
- **非結構化剪枝**：移除個別權重
- **結構化剪枝**：移除整個神經元/通道
- **動態剪枝**：運行時自適應剪枝

### 3. 知識蒸餾（Knowledge Distillation）

**核心概念：**
- 大模型（教師）→ 小模型（學生）
- 學生模型學習教師的"軟標籤"
- 保留 90-95% 性能，模型縮小 4-10倍

**NVIDIA 方法（TensorRT Model Optimizer）：**
- 結合結構化權重剪枝和知識蒸餾
- 無顯著質量損失的情況下壓縮 LLM
- 生產就緒的優化流程

**實現示例：**
```python
from transformers import AutoModelForCausalLM, Trainer, TrainingArguments
import torch.nn.functional as F

# 教師和學生模型
teacher_model = AutoModelForCausalLM.from_pretrained("large_model")
student_model = AutoModelForCausalLM.from_pretrained("small_model")

# 蒸餾損失
def distillation_loss(student_logits, teacher_logits, temperature=2.0):
    soft_labels = F.softmax(teacher_logits / temperature, dim=-1)
    student_log_probs = F.log_softmax(student_logits / temperature, dim=-1)
    loss = F.kl_div(student_log_probs, soft_labels, reduction='batchmean')
    return loss * (temperature ** 2)

# 訓練學生模型
# ... (自定義 Trainer 實現蒸餾)
```

**應用案例：**
- **DeepSeek-R1 蒸餾版本**：從 671B 蒸餾到 7B/14B/32B/70B
- 保留大部分推理能力
- 大幅降低部署成本

### 4. 組合優化技術

**最佳實踐（2025）：**
```python
# 組合：量化 + 剪枝 + 蒸餾
# 效果：模型縮小 4-5倍，速度提升 2-3倍

# 步驟 1：知識蒸餾（大→小）
student_model = distill(teacher_model, student_model)

# 步驟 2：結構化剪枝
pruned_model = structured_prune(student_model, sparsity=0.3)

# 步驟 3：量化（INT8 或 INT4）
quantized_model = quantize(pruned_model, bits=8)

# 最終結果：
# - 模型大小：原來的 20-25%
# - 推理速度：提升 2-3倍
# - 性能損失：< 5%
```

**使用建議：**
- **Quantization**：首選，效果好且易用
- **Pruning**：依賴具體硬件和任務
- **Distillation**：適合有大模型且需部署小模型
- **組合使用**：最大化效益

## 四、訓練加速技術

### 1. FlashAttention-2

**核心創新：**
- 優化注意力計算的內存訪問模式
- 減少 GPU 內存帶寬瓶頸
- 訓練速度提升 2-3倍

**使用：**
```python
from transformers import AutoModelForCausalLM

model = AutoModelForCausalLM.from_pretrained(
    "meta-llama/Llama-3.1-8B",
    attn_implementation="flash_attention_2",
    torch_dtype=torch.bfloat16
)
```

### 2. Gradient Checkpointing

**內存換時間：**
- 不存儲所有中間激活
- 反向傳播時重新計算
- 內存減少 50-70%，訓練時間增加 20-30%

```python
model.gradient_checkpointing_enable()
```

### 3. Liger Kernels

**2025年新工具：**
- 優化的自定義 CUDA 核心
- 與 FlashAttention-2 互補
- 進一步提升訓練效率

### 4. Mixed Precision Training

**FP16/BF16 訓練：**
```python
from transformers import TrainingArguments

training_args = TrainingArguments(
    fp16=True,  # 或 bf16=True
    # ...
)
```
