#### 2. 關鍵概念

**Query Rewriting（查詢改寫）**:
- **為什麼需要**: 使用者查詢往往模糊或不完整
- **如何運作**: 使用 LLM 理解意圖並重新表述
- **應用場景**: 口語化查詢、上下文相關查詢

**HyDE（假設文檔嵌入）**:
- **核心思想**: 生成"理想答案"文檔，用它來檢索
- **優勢**: 改善查詢-文檔語義匹配
- **適用**: 抽象概念、複雜問題

**Knowledge Graph RAG**:
- **特點**: 結構化知識表示
- **能力**: 多跳推理、關係查詢
- **場景**: 複雜知識網絡、實體關係密集領域

**Agent + RAG**:
- **ReAct 模式**: Reasoning（思考）+ Acting（行動）
- **工具使用**: Agent 自主選擇和使用工具
- **協作**: 多個 Agent 分工完成複雜任務

### 4. 常見陷阱與解決方案

#### 陷阱 1: 過度依賴單一技術

❌ **錯誤做法**:
```python
# 所有查詢都用同一種方法
result = vector_store.similarity_search(query)
```

✅ **正確做法**:
```python
# 根據查詢類型選擇方法
query_type = classify_query(query)
if query_type == "factual":
    result = standard_rag(query)
elif query_type == "relational":
    result = graph_rag(query)
# ...
```

#### 陷阱 2: 忽略資料品質

❌ **錯誤做法**:
```python
# 直接攝取原始文檔
docs = load_documents()
vector_store.add_documents(docs)
```

✅ **正確做法**:
```python
# 清理和預處理
docs = load_documents()
docs = clean_documents(docs)  # 去除噪音
docs = chunk_intelligently(docs)  # 智能分塊
docs = enrich_metadata(docs)  # 添加元資料
vector_store.add_documents(docs)
```

#### 陷阱 3: 缺乏錯誤處理

❌ **錯誤做法**:
```python
result = llm.invoke(query)
return result.content
```

✅ **正確做法**:
```python
try:
    result = llm.invoke(query)
    if not is_valid_response(result):
        return fallback_response(query)
    return result.content
except Exception as e:
    log_error(e)
    return error_response(query)
```

## 🎓 進階主題

### 1. 多模態 RAG

擴展系統以處理圖像、表格等：

```python
class MultimodalRAG:
    def process_document(self, doc):
        # 分離不同類型內容
        text = extract_text(doc)
        images = extract_images(doc)
        tables = extract_tables(doc)

        # 分別處理
        text_embedding = embed_text(text)
        image_descriptions = describe_images(images)
        table_summaries = summarize_tables(tables)

        # 統一索引
        return unified_index([text_embedding, image_descriptions, table_summaries])
```

### 2. 實時更新

實作增量更新機制：

```python
class IncrementalRAG:
    def add_document(self, doc, doc_id):
        """添加新文檔"""
        chunks = chunk_document(doc)
        embeddings = embed_chunks(chunks)
        self.vector_store.add(embeddings, ids=[f"{doc_id}_{i}" for i in range(len(chunks))])

    def update_document(self, doc, doc_id):
        """更新文檔"""
        self.delete_document(doc_id)
        self.add_document(doc, doc_id)

    def delete_document(self, doc_id):
        """刪除文檔"""
        self.vector_store.delete(where={"doc_id": doc_id})
```

### 3. 個性化

根據使用者偏好調整：

```python
class PersonalizedRAG:
    def query(self, query, user_profile):
        # 根據使用者背景調整檢索
        user_context = get_user_context(user_profile)
        enhanced_query = f"{query} [用戶背景: {user_context}]"

        # 個性化排序
        docs = self.retrieve(enhanced_query)
        ranked_docs = rank_by_user_preference(docs, user_profile)

        # 個性化生成
        answer = self.generate(query, ranked_docs, style=user_profile.preferred_style)
        return answer
```
