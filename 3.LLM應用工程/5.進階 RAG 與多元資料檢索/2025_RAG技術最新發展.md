# 2025年 RAG 技術最新發展與實踐

## 概述

檢索增強生成（Retrieval-Augmented Generation, RAG）是 2025年 LLM 應用的核心技術之一。隨著技術的快速演進，RAG 已經從簡單的文字檢索發展為複雜的多模態、多智能體系統。本文檔全面介紹2025年 RAG 的最新技術發展。

## 二、2025年 RAG 技術突破

### 1. 混合搜索（Hybrid Search）成為標準

**技術組合：**
- **語義搜索**（Semantic Search）：基於向量相似度
- **關鍵詞搜索**（BM25）：基於詞彙匹配
- **重排序器**（Re-ranker）：確保最相關結果排在前面

**為什麼混合搜索？**
- 語義搜索：捕獲意圖和上下文
- BM25：精確匹配關鍵詞
- 結合兩者：最佳召回率和精確度

**實現示例：**
```python
from llama_index import VectorStoreIndex, SimpleDirectoryReader
from llama_index.retrievers import BM25Retriever, VectorIndexRetriever
from llama_index.query_engine import RetrieverQueryEngine
from llama_index.response_synthesizers import get_response_synthesizer
from llama_index.indices.postprocessor import CohereRerank

# 加載文檔
documents = SimpleDirectoryReader('data').load_data()
index = VectorStoreIndex.from_documents(documents)

# 建立混合檢索器
vector_retriever = VectorIndexRetriever(index=index, similarity_top_k=10)
bm25_retriever = BM25Retriever.from_defaults(docstore=index.docstore, similarity_top_k=10)

# 重排序器
reranker = CohereRerank(api_key="your-api-key", top_n=5)

# 組合查詢引擎
query_engine = RetrieverQueryEngine(
    retriever=vector_retriever,
    response_synthesizer=get_response_synthesizer(),
    node_postprocessors=[reranker]
)

# 查詢
response = query_engine.query("What is the main topic?")
```

### 2. GraphRAG 的崛起

**核心概念：**
- 將知識圖譜（Knowledge Graph）與 RAG 結合
- 提供結構化的知識表示
- 增強推理和可解釋性

**優勢：**
- **關係推理**：理解實體之間的複雜關係
- **可解釋性**：提供推理路徑
- **結構化知識**：有組織的資訊表示

**技術架構：**
```
文檔 → 實體提取 → 知識圖譜構建
         ↓
    關係識別 → 圖譜擴展
         ↓
查詢 → 圖譜遍歷 → 相關子圖 → LLM 生成
```

**實現示例：**
```python
from llama_index import KnowledgeGraphIndex, SimpleDirectoryReader
from llama_index.graph_stores import Neo4jGraphStore
from llama_index.storage.storage_context import StorageContext

# 連接 Neo4j
graph_store = Neo4jGraphStore(
    username="neo4j",
    password="password",
    url="bolt://localhost:7687",
    database="neo4j"
)

# 建立存儲上下文
storage_context = StorageContext.from_defaults(graph_store=graph_store)

# 構建知識圖譜索引
documents = SimpleDirectoryReader('data').load_data()
kg_index = KnowledgeGraphIndex.from_documents(
    documents,
    storage_context=storage_context,
    max_triplets_per_chunk=10
)

# 查詢
query_engine = kg_index.as_query_engine(
    include_text=True,
    response_mode="tree_summarize"
)
response = query_engine.query("Explain the relationship between X and Y")
```

**應用場景：**
- 企業知識管理
- 醫療診斷輔助
- 金融風險分析
- 科學研究輔助

### 3. 多模態 RAG（Multimodal RAG）

**2025年重大進展：**
- RAG 不再局限於文字
- 支持圖像、音頻、影片檢索
- 跨模態理解和生成

**技術組件：**
- **多模態嵌入**：CLIP、ImageBind 等
- **多模態向量資料庫**：Qdrant、Weaviate
- **多模態 LLM**：GPT-4V、Gemini、Claude 3

**實現示例：**
```python
from llama_index.multi_modal_llms import OpenAIMultiModal
from llama_index import SimpleDirectoryReader, VectorStoreIndex
from llama_index.vector_stores import QdrantVectorStore
import qdrant_client

# 初始化 Qdrant
client = qdrant_client.QdrantClient(path="./qdrant_data")
vector_store = QdrantVectorStore(client=client, collection_name="multimodal")

# 加載多模態文檔（包含圖像）
documents = SimpleDirectoryReader(
    'data',
    file_extractor={".jpg": ImageReader(), ".png": ImageReader()}
).load_data()

# 建立多模態索引
index = VectorStoreIndex.from_documents(
    documents,
    vector_store=vector_store
)

# 多模態查詢
multimodal_llm = OpenAIMultiModal(model="gpt-4o")  # GPT-4o 支援多模態
query_engine = index.as_query_engine(
    llm=multimodal_llm,
    image_similarity_top_k=5
)

response = query_engine.query("Find images related to AI infrastructure")
```

### 4. 語義層與上下文工程（Beyond RAG）

**概念演進：**
- RAG 正在演化為更廣泛的"上下文工程"（Context Engineering）
- 語義層（Semantic Layer）提供可解釋、可治理的上下文
- 適配性和可解釋性成為關鍵

**核心技術：**
- **Context Governance**：上下文治理
- **Explainability**：可解釋性
- **Adaptive Context**：自適應上下文

**與傳統 RAG 的區別：**
| 傳統 RAG | 語義層 RAG |
|---------|-----------|
| 簡單文字檢索 | 結構化知識表示 |
| 向量搜索 | 語義理解 + 推理 |
| 黑盒檢索 | 可解釋路徑 |
| 靜態上下文 | 動態自適應 |

## 五、RAG 最佳實踐（2025）

### 1. 文檔預處理

**關鍵步驟：**
```python
from langchain.text_splitter import RecursiveCharacterTextSplitter

# 智能分塊
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200,
    length_function=len,
    separators=["\n\n", "\n", " ", ""]
)

chunks = text_splitter.split_documents(documents)
```

**最佳實踐：**
- Chunk size：500-1500 字符（視具體情況）
- Chunk overlap：10-20% 的 chunk size
- 保持語義完整性
- 包含元資料（來源、時間戳等）

### 2. 嵌入模型選擇

**2025年推薦：**
- **OpenAI text-embedding-3-large**：高品質通用嵌入
- **Cohere Embed v3**：多語言優秀
- **BGE-large**：開源高性能
- **E5-mistral**：長文字處理

**對比：**
| 模型 | 維度 | 語言 | 性能 | 成本 |
|-----|------|------|------|------|
| OpenAI ada-003 | 1536 | 多語言 | 高 | 中 |
| Cohere Embed v3 | 1024 | 多語言 | 高 | 中 |
| BGE-large | 1024 | 多語言 | 中高 | 免費 |
| E5-mistral | 4096 | 英文為主 | 高 | 免費 |

### 3. 檢索策略優化

**多階段檢索：**
```python
# Stage 1: 粗檢索（Recall）
initial_results = vector_search(query, top_k=50)

# Stage 2: 重排序（Precision）
reranked_results = reranker.rerank(query, initial_results, top_n=10)

# Stage 3: 上下文壓縮
compressed_context = context_compressor.compress(reranked_results)
```

**檢索策略：**
- **Dense Retrieval**：向量相似度搜索
- **Sparse Retrieval**：BM25 關鍵詞匹配
- **Hybrid Retrieval**：結合上述兩者
- **Re-ranking**：使用 Cohere Rerank 或 ColBERT

### 4. 提示工程（Prompt Engineering）

**RAG 提示模板：**
```python
from langchain.prompts import PromptTemplate

template = """使用以下上下文來回答問題。如果你不知道答案，就說你不知道，不要試圖編造答案。

上下文：
{context}

問題：{question}

有用的回答："""

prompt = PromptTemplate(
    template=template,
    input_variables=["context", "question"]
)
```

**最佳實踐：**
- 明確指示使用上下文
- 要求引用來源
- 處理未知情況
- 控制回答長度

### 5. 評估與監控

**評估指標：**
- **Retrieval Precision**：檢索精確度
- **Retrieval Recall**：檢索召回率
- **Answer Relevance**：回答相關性
- **Faithfulness**：忠實度（是否基於上下文）

**評估工具：**
```python
from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy, context_precision

# 評估
results = evaluate(
    dataset,
```

## 六、進階 RAG 架構

### 1. 自適應 RAG（Adaptive RAG）

**核心思想：**
- 根據查詢類型動態選擇檢索策略
- 簡單查詢 → 直接回答
- 複雜查詢 → 多步檢索

**實現：**
```python
def adaptive_rag(query):
    # 分類查詢
    query_type = classify_query(query)

    if query_type == "simple":
        return simple_search(query)
    elif query_type == "complex":
        return multi_step_search(query)
    elif query_type == "factual":
        return knowledge_graph_search(query)
```

### 2. 多跳推理 RAG（Multi-Hop RAG）

**處理複雜問題：**
```python
def multi_hop_rag(query):
    # 第一跳
    context1 = retrieve(query)
    sub_query = generate_sub_query(query, context1)

    # 第二跳
    context2 = retrieve(sub_query)

    # 合成答案
    answer = synthesize(query, context1, context2)
    return answer
```

### 3. Agent-based RAG

**智能代理增強：**
- Agent 決定何時檢索
- Agent 選擇檢索策略
- Agent 驗證檢索結果

**架構：**
```python
from langchain.agents import initialize_agent, Tool
from langchain.tools import BaseTool

# 定義 RAG 工具
rag_tool = Tool(
    name="RAG Search",
    func=rag_search,
    description="用於搜索知識庫的工具"
)

# 建立 Agent
agent = initialize_agent(
    tools=[rag_tool],
    llm=llm,
    agent="zero-shot-react-description"
)

# 使用 Agent
result = agent.run("複雜查詢")
```
