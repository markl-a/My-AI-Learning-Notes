## 🎨 圖片生成示例

### 01_stable_diffusion_basic.py
**基礎圖片生成 - Stable Diffusion**

功能：
- ✓ 基本文生圖功能
- ✓ 批量生成
- ✓ 參數調整（步數、引導強度、種子）
- ✓ 記憶體優化技術

使用場景：
- 創意設計
- 產品原型圖
- 藝術創作
- 營銷素材

快速開始：
```python

generate_image_basic(
    prompt="a beautiful landscape with mountains and lake",
    output_path="landscape.png"
)
```

- ✓ Canny 邊緣控制

## 🎬 影片生成示例

### 01_stable_video_diffusion.py
**Stable Video Diffusion - 圖片轉影片**

功能：
- ✓ 單圖生成短視頻（14-25幀）
- ✓ 運動強度控制
- ✓ 批量處理
- ✓ 長視頻拼接

使用場景：
- 產品展示動畫
- 社交媒體內容
- 概念演示
- 動態背景

快速開始：
```python
from 01_stable_video_diffusion import VideoGenerator

generator = VideoGenerator()
generator.generate_video(
    image=input_image,
    num_frames=25,
    motion_bucket_id=127,
    output_path="video.mp4"
)
```

硬體需求：
- GPU: 12GB+ VRAM 推薦
- RAM: 16GB+
- 存儲: 10GB+ 用於模型

## 🎵 音樂生成示例

### 01_musicgen_basic.py
**MusicGen - AI 音樂生成**

功能：
- ✓ 文字描述生成音樂
- ✓ 多種音樂風格
- ✓ 參數精細控制
- ✓ 循環音樂生成
- ✓ 批量音樂庫創建

使用場景：
- 背景音樂創作
- 遊戲配樂
- 影片配樂
- 播客開場/結尾

快速開始：
```python
from 01_musicgen_basic import MusicGenerator

generator = MusicGenerator(model_size="small")
generator.generate_and_save(
    prompt="upbeat pop music with electric guitar",
    output_path="music.wav",
    duration=15.0
)
```

模型選擇：
- small (300M): 快速，適合測試
- medium (1.5B): 平衡質量和速度
- large (3.3B): 最佳質量
- melody (1.5B): 支持旋律條件

## 💡 使用建議

### 記憶體優化
1. **圖片生成**
   - 使用 `enable_attention_slicing()`
   - 降低圖片解析度（512x512 → 768x768）
   - 使用較少的推理步數

2. **影片生成**
   - 使用 `enable_model_cpu_offload()`
   - 減少幀數（25 → 14）
   - 調整 `decode_chunk_size`

3. **音樂生成**
   - 使用較小的模型
   - 減少生成時長
   - 批量處理時注意間隔

### 質量優化
1. **提示詞技巧**
   - 使用具體描述
   - 添加質量修飾詞（high quality, detailed）
   - 使用負向提示詞

2. **參數調整**
   - 增加推理步數（50-100）
   - 調整引導強度（7.5-12）
   - 使用固定種子保證可重現

3. **後處理**
   - 影片: 幀插值、穩定化
   - 音樂: 淡入淡出、混響
   - 圖片: 超分辨率、色彩校正

## 🔧 故障排除

### 常見問題

1. **CUDA Out of Memory**
   - 減少批次大小
   - 降低解析度/幀數/時長
   - 啟用記憶體優化選項
   - 使用較小的模型

2. **生成結果不理想**
   - 優化提示詞
   - 調整採樣參數
   - 增加推理步數
   - 嘗試不同種子

3. **模型下載失敗**
   - 檢查網絡連接
   - 設置 HuggingFace 鏡像
   - 手動下載後放置到指定目錄

4. **ImportError**
   - 確認所有依賴已安裝
   - 檢查 CUDA 版本兼容性
   - 更新到最新版本
