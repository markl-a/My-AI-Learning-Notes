# ⚠️ 入門前置:Generative UI

## 目標讀者
後端 / LLM 應用工程師,API 與 agent 都串過,**但沒寫過 React、也沒做過 LLM 串流 UI**。如果你只想讓 LLM 回文字,看 `3.LLM應用工程` 就夠了;Generative UI 是讓 LLM **動態產出 / 挑選 UI 元件**,所以前端是繞不開的。

## 三層先決
1. **React 基本概念**:component、props、state、`useState` / `useEffect`、JSX。建議先跑完 [react.dev](https://react.dev) 的 Tic-Tac-Toe 教學(2 小時)。
2. **LLM tool calling**(必備,Gen UI 的本質就是把 tool result 渲染成 UI):
   - [`../3.LLM應用工程/3.Agent/`](../3.LLM應用工程/3.Agent/)
   - [`../3.LLM應用工程/11.MCP協議與工具調用/`](../3.LLM應用工程/11.MCP協議與工具調用/)
3. **Tailwind CSS 基礎**:utility class(`flex`、`gap-2`、`rounded-lg`),因為 shadcn/ui 與 v0 全套都跑在 Tailwind 上。

## Generative UI vs AI Coding 差別(1 分鐘)
| | 受眾 | 產物 | 何時生 |
| --- | --- | --- | --- |
| **AI Coding**(Cursor / Copilot) | 工程師 | source code,人類審閱後 commit | 開發期 |
| **Generative UI** | end-user | rendered component(直接看到的 UI) | runtime,每次對話 |

關鍵差異:Gen UI 的「程式碼」是給 LLM / 框架解析的中介產物,user 看不到也不該看到。

## 三大範式(1 分鐘)
1. **Streaming components**:RSC + `streamUI`,LLM 邊生 token 邊把 React tree 串到瀏覽器(Vercel AI SDK)。
2. **Tool-rendered UI**:LLM 呼叫 tool → tool 回傳 typed data → 前端用對應的 React component 渲染(weather card、股票圖)。
3. **Generative form**:LLM 根據對話脈絡動態決定要問哪些欄位、用哪種 input(slider / multi-select / file upload)。

## 30 分鐘動手
- **零安裝路線**:開 [v0.dev](https://v0.dev) 帳號,輸入「a pricing card with 3 tiers」,看它生出可複製的 React + shadcn/ui code。
- **本地路線**:`pnpm create next-app` → 加 `ai` SDK + `shadcn/ui`,做一個聊天框,當 user 問天氣時用 `tool` 渲染一張 weather card 而不是純文字。

## 名詞速查
| 詞 | 一句話 |
| --- | --- |
| RSC | React Server Components,server 端渲染後串到 client |
| `streamUI` | Vercel AI SDK 的 API,讓 LLM 直接決定渲染哪個 component |
| Tool-rendered UI | 把 tool calling 結果綁到 typed React component |
| A2UI | Agent-to-UI 協議草案,讓 agent 跨框架描述 UI 意圖 |
| shadcn/ui | 不是 npm 套件,是「複製貼上」的 component 集合(Radix + Tailwind) |
| Radix primitives | 無樣式但有完整 a11y 與 keyboard 行為的底層 component |
