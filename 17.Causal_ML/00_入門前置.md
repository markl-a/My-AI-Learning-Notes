# 17.Causal_ML 入門前置

> 本檔是進入 `17.Causal_ML/README.md` 之前的**橋樑文件**。
> 因果推論的最大障礙不是技術,而是**世界觀切換**——習慣 ML 的 P(Y|X) 後,要學會問 P(Y|do(X))。本檔幫你跨過這道坎。

## 為什麼相關 ≠ 因果

### 例 1: Simpson's Paradox
某醫院統計:總體看,A 療法治癒率 78% > B 療法治癒率 83% ── 等等,B 比較高?然而分開看輕症/重症,**A 療法在兩組都贏過 B**。原因:醫生把重症都分給了 A,組間病人分布不同。直接用 P(治癒|療法) 會得到完全反向的結論。

### 例 2: Selection Bias
你想評估「上 MOOC 對薪資的影響」,於是訪問所有上過 MOOC 的人。問題:會主動上 MOOC 的人本來就比較積極/年輕,薪資高未必是 MOOC 的功勞。**抽樣方式本身就把因果訊號污染了**。

這兩個例子告訴你:沒有正確 framework,再多資料也學不到因果。

## 三層先決條件

1. 會 `train_test_split` 並懂為什麼要分。
2. 會跑 OLS / linear regression 並解讀係數。
3. 看過 LightGBM / XGBoost 至少一次,知道什麼叫 feature importance。

具備這三項就能上手 Causal ML——**不需要 RL 或 deep learning 背景**。

## 兩派 30 秒摘要

### Pearl 學派 (結構因果模型 SCM)
**做法**: 先畫 DAG (causal graph),用 do-calculus 三條規則機械式推導識別公式。
**強項**: 視覺化、能處理 mediator/collider 等複雜結構、機制透明。
**代表**: Judea Pearl, Elias Bareinboim。

### Rubin 學派 (Potential Outcomes)
**做法**: 寫下 estimand (例如 ATE = E[Y(1) - Y(0)]),設計 estimator 估它。
**強項**: 統計學家熟悉、直接對接 RCT / quasi-experiment 文獻。
**代表**: Donald Rubin, Guido Imbens, Susan Athey。

**關鍵認知**: 兩派**形式上等價**,只是語言不同。實務上 Pearl 派愛畫圖,Rubin 派愛寫公式,看你哪邊上手快。

## 名詞速查

- **ATE (Average Treatment Effect)**: 母體平均因果效應 E[Y(1) − Y(0)]。
- **CATE (Conditional ATE)**: 給定特徵 X 下的個別化效應,推薦系統 uplift modeling 主要目標。
- **Backdoor**: 從 treatment 到 outcome 的「後門路徑」,需要 condition 上去阻斷混淆。
- **Frontdoor**: 當無法觀測 confounder 時,透過 mediator 識別效應的 Pearl 招式。
- **IV (Instrumental Variable)**: 工具變數——只透過 treatment 影響 outcome 的外生變數,計量經濟學主力。
- **DML (Double Machine Learning)**: Chernozhukov 2018,把 nuisance function 用 ML 估、target parameter 維持 √n 收斂率,EconML 預設方法。
